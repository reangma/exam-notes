1. 학습 종류

제품의 측정값 X와 정상/불량 정답 Y를 함께 제공해 분류 모델을 학습했다. 가장 알맞은 설명은?

  1. 비지도학습이다. 제품을 나누기 때문이다.
  2. 지도학습이다. 입력과 정답이 함께 주어졌기 때문이다.
  3. 강화학습이다. 오답을 수정하기 때문이다.
  4. 정답이 0/1이므로 반드시 회귀이다.
정답·해설

B. X와 Y가 함께 주어지는 지도학습입니다. A: 군집화와 분류를 혼동했습니다. C: 오답 수정만으로 강화학습이 되지 않습니다. D: 0/1은 범주를 표시한 값입니다.

2. 데이터와 평가

다음 중 올바른 것은?

  1. 학습 데이터 성능이 좋으면 새로운 데이터의 성능도 반드시 좋다.
  2. 테스트 정답을 반복 확인하며 모델을 수정하면 공정한 최종 평가가 된다.
  3. 데이터 한 건을 관측치라 하고, 그 건의 특성 항목을 변수라고 한다.
  4. 비지도학습에는 입력 X도 없다.
정답·해설

C. 학생 한 명이 관측치이고 키·몸무게 등이 변수입니다. A: 과적합 가능성이 있습니다. B: 테스트셋에 간접적으로 맞추게 됩니다. D: 비지도학습에도 X는 있습니다.

4. XOR과 비선형성

단층 퍼셉트론의 한계와 다층 신경망에 대한 설명으로 가장 적절한 것은?

  1. XOR은 직선 하나로 분리할 수 없으며, 은닉층과 비선형 활성화가 이를 표현하는 데 필요하다.
  2. XOR은 입력이 두 개라서 어떤 신경망으로도 해결할 수 없다.
  3. 선형 변환만 여러 번 쌓으면 반드시 비선형 모델이 된다.
  4. 활성화 함수는 학습률과 같은 개념이다.
정답·해설

A. XOR은 선형 분리가 되지 않습니다. B: 다층 비선형 모델로 표현할 수 있습니다. C: 선형·아핀 변환의 합성은 하나의 선형·아핀 변환으로 합쳐집니다. D: 활성화는 값 변환, 학습률은 업데이트 크기 설정입니다.

5. 행렬 크기와 파라미터 수

열벡터 x가 10×1이고 은닉 노드가 20개이다. h=σ(Wx+b)일 때 W의 크기와 이 층의 총 파라미터 수는? 편향을 포함한다.

  1. 10×20, 210개
  2. 20×10, 220개
  3. 20×20, 420개
  4. 10×1, 30개
정답·해설

B. (20×10)(10×1)=20×1. 가중치 200개와 편향 20개로 총 220개입니다. A는 곱셈 방향과 편향 개수가 맞지 않습니다.

6. 활성화 함수

ReLU(−3), ReLU(2), sigmoid(0)을 순서대로 바르게 나열한 것은?

  1. −3, 2, 0
  2. 0, 1, 1
  3. 0, 2, 0.5
  4. −0.3, 2, 0.5
정답·해설

C. ReLU=max(0,z)이므로 음수는 0, 양수는 그대로입니다. sigmoid(0)=1/(1+1)=0.5입니다. D의 첫 값은 기울기 0.1의 Leaky ReLU와 혼동한 값입니다.

복습: 활성화 함수 · 2주차 pp. 94~95.

7. 손실 함수

정답이 [2,4], 예측이 [1,6]일 때 MSE와, 분류의 교차 엔트로피에 대한 설명이 모두 맞는 것은?

  1. MSE=2.5, 정답 클래스의 예측 확률이 커질수록 교차 엔트로피는 작아진다.
  2. MSE=5, 정답 클래스의 예측 확률이 커질수록 교차 엔트로피는 작아진다.
  3. MSE=0.5, 교차 엔트로피는 항상 0~1이다.
  4. MSE=2.5, softmax 자체가 교차 엔트로피 손실이다.
정답·해설

A. MSE=[(1−2)²+(6−4)²]/2=5/2=2.5. B는 평균을 빠뜨렸습니다. C: 교차 엔트로피는 1보다 클 수 있습니다. D: softmax는 확률 변환, CE는 손실입니다.

복습: 손실 함수 · 2주차 pp. 89~90의 식 활용.

8. 경사하강법과 optimizer

w=2, α=0.1, ∂L/∂w=−3일 때 경사하강법의 새 w와 Adam 설명이 맞는 것은?

  1. w=1.7, Adam은 항상 전역 최적해를 보장한다.
  2. w=2.3, Adam은 기울기를 사용하지 않는다.
  3. w=1.7, Adam은 손실 함수이다.
  4. w=2.3, Adam은 기울기의 평균과 제곱 평균을 이용한다.
정답·해설

D. w새값=2−0.1×(−3)=2.3입니다. Adam은 optimizer이며 방향 정보와 적응적인 크기 조정을 함께 사용합니다. 전역 최적해를 보장하지 않습니다.

복습: 경사하강법, Adam · 2주차 pp. 96~103.

9. Epoch와 iteration

학습 데이터 1,000개, batch size 64, 3 epoch이다. 마지막 작은 batch도 사용하며 batch마다 한 번 업데이트한다. 총 업데이트 횟수는?

  1. 45회
  2. 48회
  3. 64회
  4. 3,000회
정답·해설

B. ceil(1000/64)=16회/epoch이므로 16×3=48회입니다. A는 마지막 40개 묶음을 버린 계산이고, D는 데이터 처리 횟수와 업데이트 횟수를 혼동했습니다.

복습: Batch·epoch·iteration · 2주차 p. 104.

10. 출력층 역전파

sigmoid 출력과 E=(1/2)(t−o)²를 사용한다. α=0.1, t=1, o=0.6, h=0.5일 때 은닉→출력 가중치에 더할 수정량 Δw는?

  1. 0.04
  2. −0.0048
  3. 0.0048
  4. 0.0096
정답·해설

C. Δw=α(t−o)o(1−o)h=0.1×0.4×0.6×0.4×0.5=0.0048. A는 미분 계수와 입력을 빠뜨렸고 B는 부호를 뒤집었습니다. D는 h 대신 1을 곱한 편향 수정량입니다.

복습: 출력층 역전파 · EBPA pp. 8~9의 식 활용.

11. Seq2Seq와 Attention

기본 Seq2Seq의 정보 병목을 Attention이 완화하는 방법은?

  1. 출력 시점마다 인코더의 모든 상태를 참고하고 필요한 정보에 큰 비율을 부여한다.
  2. 인코더의 마지막 상태만 더 작은 벡터로 만든다.
  3. 모든 입력 단어를 항상 동일한 비율로 사용한다.
  4. 출력 문장의 길이를 입력 문장과 같게 고정한다.
정답·해설

A. 고정 요약 하나에만 의존하지 않고 현재 출력에 맞는 정보를 다시 참고합니다. B는 병목을 해소하는 방법이 아니고, C는 Attention 비율이 달라진다는 점을 놓쳤습니다. D: 입력과 출력 길이는 달라도 됩니다.

복습: Seq2Seq의 한계 · Transformer pp. 10~18.

12. Scaled dot-product Attention

Attention(Q,K,V)=softmax(QKᵀ/√d_k)V에 대한 설명 중 맞는 것은?

  1. Q와 V를 비교해 K를 가중합한다.
  2. d_k는 문장 속 단어의 개수이다.
  3. softmax를 적용한 전체 행렬 원소의 합은 항상 1이다.
  4. Q·K로 연관성 점수를 만들고, 행별로 정규화한 비율로 V를 가중합한다.
정답·해설

D. A는 K·V 역할이 바뀌었습니다. B: d_k는 key 벡터 차원입니다. C: 각 행의 합이 1이며, 행이 여러 개면 전체 합은 일반적으로 1이 아닙니다.

복습: Scaled attention · Transformer pp. 37~39.

13. Multi-head 행렬 크기

토큰 4개, d_model=512, head 수 8, d_k=d_v=64이다. 한 head의 비율 행렬, 한 head의 출력, 8개 head를 연결한 결과의 크기는 차례대로?

  1. 4×64, 4×4, 4×512
  2. 4×4, 4×64, 4×512
  3. 512×512, 4×64, 32×64
  4. 4×4, 4×512, 4×4096
정답·해설

B. QKᵀ는 (4×64)(64×4)=4×4, 여기에 V(4×64)를 곱하면 4×64입니다. 8개를 특징 방향으로 연결하면 4×512입니다. 토큰 행을 이어 붙이는 것이 아닙니다.

복습: Attention 행렬 크기 · Transformer pp. 36~45.

14. 위치 인코딩과 FFNN

강의의 Transformer 구조에 대한 설명으로 올바른 것은?

  1. 위치 벡터를 임베딩에 이어 붙여 d_model을 두 배로 만든다.
  2. 홀수 번째 단어에는 cos, 짝수 번째 단어에는 sin만 사용한다.
  3. 위치 벡터는 임베딩에 더하며, position-wise FFNN은 각 위치에 동일한 변환을 독립 적용한다.
  4. Add는 서로 다른 크기의 벡터도 자동으로 이어 붙이는 연산이다.
정답·해설

C. 위치 인코딩은 같은 차원 벡터의 덧셈입니다. sin·cos의 짝수/홀수는 벡터 안 차원 번호이고, residual의 Add도 같은 크기끼리 더하는 것입니다.

복습: 위치 인코딩, FFNN · Transformer pp. 28~29, 48~50.

15. 디코더와 마스킹

다음 중 올바른 것은?

  1. Cross-Attention의 Q는 디코더, K·V는 인코더 출력에서 오며, look-ahead mask는 미래 출력 토큰의 참고를 막는다.
  2. Cross-Attention의 Q·K·V는 모두 인코더 출력에서 온다.
  3. 미래 위치의 softmax 전 점수를 0으로 바꾸면 확률이 반드시 0이 된다.
  4. 학습 시 정답을 입력하므로 look-ahead mask는 필요 없다.
정답·해설

A. 디코더가 질의하고 인코더 정보를 참고합니다. B는 self-attention과 혼동했습니다. C: e⁰=1이므로 0 확률이 보장되지 않습니다. D: 정답을 한꺼번에 입력하므로 미래 정답 누출을 막는 마스크가 필요합니다.

복습: 세 종류 Attention, 마스킹 · Transformer pp. 52~57.

서술형 2문제

아래 두 주제는 주요 내용을 연결해 쓰기 위한 연습 주제이며 실제 출제 주제를 확정한 것이 아닙니다.

서술형 1. 신경망의 학습과 오류 역전파

sigmoid를 사용하는 입력–은닉–출력 신경망에서 손실이 E=(1/2)Σₖ(tₖ−oₖ)²일 때, 학습 과정을 설명하시오. 순전파·손실·연쇄법칙·경사하강법을 포함하고, 은닉→출력 가중치의 수정식을 쓰시오. 은닉층의 오차를 구할 때 여러 출력의 영향을 합치는 이유도 설명하시오.

답안에 꼭 들어갈 키워드
  • 순전파: 가중합 후 활성화, 예측 o 계산
  • 손실: 실제 t와 예측 o 차이
  • 연쇄법칙으로 가중치별 기울기 계산
  • 출력층부터 앞쪽으로 역전파
  • Δwₖⱼ=α(tₖ−oₖ)oₖ(1−oₖ)hⱼ
  • 은닉 노드는 여러 출력에 영향을 주므로 경로별 영향을 합산
  • 학습률에 따라 기울기 반대 방향으로 갱신
답안 예시

먼저 입력값에 가중치를 곱해 더하고 sigmoid를 적용하여 은닉값과 출력 예측값을 순전파로 계산한다. 실제 정답과 예측값의 제곱오차를 손실로 구한 다음, 연쇄법칙을 이용해 출력층부터 앞쪽으로 각 가중치에 대한 손실의 기울기를 계산한다. 은닉→출력 가중치의 기울기는 (oₖ−tₖ)oₖ(1−oₖ)hⱼ이므로 경사하강법의 수정량은 Δwₖⱼ=α(tₖ−oₖ)oₖ(1−oₖ)hⱼ이고, 이를 기존 가중치에 더한다. 은닉층에는 직접 주어진 정답이 없으므로 연결된 출력들의 오차 신호에 해당 연결 가중치를 곱해 합하고, 은닉층 활성화 함수의 미분을 곱해 기울기를 구한다. 모든 기울기를 같은 갱신 전 가중치로 계산한 후 파라미터를 갱신하며 이 과정을 반복한다.

자기 점검과 짧은 답안 틀

핵심 틀: ‘순전파로 예측 → 손실 계산 → 연쇄법칙으로 역전파 → 학습률을 곱해 기울기 반대로 갱신’.

공식의 (t−o) 부호와 업데이트의 +를 맞췄는지, 출력층 식의 마지막에 x가 아니라 h를 썼는지 확인하세요. ‘오차만큼 그냥 뺀다’는 설명으로 끝내지 않습니다.

서술형 2. Transformer의 구조와 Attention

기본 Seq2Seq의 한계를 제시하고 Transformer의 인코더·디코더 구조를 설명하시오. Self-Attention의 Q·K·V, Multi-head, 위치 인코딩, look-ahead mask, Encoder–Decoder Attention의 Q·K·V 출처를 포함하시오.

답안에 꼭 들어갈 키워드
  • 기본 Seq2Seq의 고정 문맥 벡터 병목, 순환 계산의 장거리 학습·병렬화 한계
  • RNN 대신 Attention을 핵심으로 사용
  • 같은 시퀀스에서 서로 다른 변환으로 Q·K·V 생성
  • softmax(QKᵀ/√d_k)V
  • head별 가중치, 병렬 계산, concat, 출력 변환
  • 임베딩에 위치 정보 덧셈
  • 인코더: Self-Attention + FFNN
  • 디코더: Masked Self-Attention + Cross-Attention + FFNN
  • Cross-Attention의 Q는 디코더, K·V는 인코더
  • 미래 정답 누출 차단, Add & Norm
답안 예시

기본 Seq2Seq는 입력 전체를 고정 크기의 문맥 벡터 하나로 압축해 긴 문장에서 정보 손실이 발생할 수 있고, RNN의 순차 처리 때문에 병렬화와 장거리 정보 학습에 한계가 있다. Transformer는 RNN 없이 Attention을 핵심으로 입력 위치들의 관계를 계산하며, 순서 정보를 위해 임베딩에 위치 인코딩을 더한다. Self-Attention은 같은 시퀀스를 서로 다른 가중치로 변환하여 Q·K·V를 만들고, softmax(QKᵀ/√d_k)V로 관련 정보의 가중합을 구한다. Multi-head는 서로 다른 가중치를 가진 Attention을 병렬 수행하고 결과를 연결한 뒤 출력 변환한다.

인코더는 Multi-head Self-Attention과 FFNN으로 구성된다. 디코더는 Masked Self-Attention, Encoder–Decoder Attention, FFNN으로 구성된다. look-ahead mask는 미래 출력 토큰의 정보를 참고하지 못하게 하여 학습 중 정답 누출을 막는다. Encoder–Decoder Attention의 Q는 디코더에서, K·V는 인코더 출력에서 온다. 각 서브층에는 잔차 연결과 Layer Normalization이 적용되고, 최종 출력은 선형 변환과 softmax를 통해 다음 토큰 확률로 바뀐다.

자기 점검과 짧은 답안 틀

핵심 틀: ‘고정 요약의 한계 → Attention으로 필요한 정보 참고 → RNN 없는 Transformer → 위치 정보 추가 → 인코더/디코더 구성 → 미래 마스크와 Cross-Attention 출처’.

Q=K=V를 ‘숫자도 동일’이라고 쓰지 않았는지, 위치 인코딩을 concat이라 하지 않았는지, 학습 병렬화와 순차 생성을 구분했는지 확인하세요.
