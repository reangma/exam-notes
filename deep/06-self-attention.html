6. Self-Attention과 Multi-head 계산

출처: #3 Transformer.pdf pp. 24~46. 위치 정보·전체 구조는 다음 장에서 이어집니다.

한 문장부터

Self-Attention은 같은 문장 안의 단어들이 서로를 참고하여 자기 표현을 고치는 것입니다. Multi-head는 이를 서로 다른 학습 가중치로 여러 번 병렬 수행합니다.

Transformer가 바꾼 것

출처: Transformer pp. 24~27.

2017년 Attention Is All You Need에서 제시된 Transformer는 인코더·디코더 구조를 유지하면서 RNN의 순환 계산을 사용하지 않고 Attention을 핵심으로 사용합니다.

RNN은 앞 단어의 상태 계산이 끝나야 다음 단어의 상태를 계산할 수 있습니다. Transformer는 입력 토큰들의 관계를 행렬로 계산하여 여러 위치를 병렬로 처리할 수 있습니다. 단, 생성 시 다음 단어가 앞선 출력에 의존하는 것까지 없어지는 것은 아닙니다.

‘Attention만 있으면 된다’는 제목 때문에 FFNN·정규화·임베딩 등이 없다고 생각하지 마세요. 실제 구조에는 이 구성요소들도 들어갑니다.

Self는 ‘나 하나만 본다’가 아니다

출처: Transformer pp. 31~35.

예를 들어 ‘The animal … it …’에서 it이 무엇을 가리키는지 알려면 앞의 animal 등을 참고해야 합니다. Self-Attention은 같은 입력 시퀀스 안의 다른 단어들까지 비교합니다. 자기 자신도 참고 후보에 포함할 수 있습니다.

Q=K=V라는 축약의 정확한 뜻

Self-Attention은 Q, K, V의 출처가 같은 시퀀스라는 뜻입니다. 서로 다른 WQ, WK, WV를 곱하므로 Q, K, V의 숫자가 반드시 같은 것은 아닙니다. pp. 55~56의 ‘Q==K==V’는 이 출처를 강조한 축약으로 읽습니다.

같은 입력에서 Q, K, V를 따로 만들기

출처: Transformer pp. 35~36, 39.

Q = XWQ
K = XWK
V = XWV

X는 여러 단어 벡터를 행으로 쌓은 표입니다. WQ, WK, WV는 학습하는 변환 행렬입니다. 단어마다 완전히 별개의 W를 갖는 것이 아니라 한 head 안에서는 같은 W를 모든 위치에 적용합니다.

기호뜻강의 예시
n 또는 seq_len입력 단어·토큰 수I am a student → 4
d_model모델 내부 단어 표현의 폭512
num_heads 또는 H동시에 수행할 head 개수8
d_k, d_v한 head의 K·V 차원512/8=64

Q와 K는 내적해야 하므로 한 head에서 차원이 맞아야 합니다. 강의 기본 구조는 dk=dv=64를 사용합니다. 512·8·64는 예시 설정이며 모든 Transformer에 고정된 숫자가 아닙니다.

Scaled dot-product Attention 한 줄 읽기

출처: Transformer pp. 37~39.

Attention(Q,K,V) = softmax(QKᵀ / √d_k)V
  1. QKᵀ: 각 질의 Q와 모든 키 K의 내적 점수를 구합니다.
  2. /√d_k: 점수의 크기를 조절합니다.
  3. softmax: 각 질의에 대해 키들을 참고할 비율을 만듭니다. 행별 합이 1입니다.
  4. ×V: 비율대로 V들을 가중합하여 새로운 표현을 만듭니다.

왜 √d_k로 나누나?

차원이 커지면 내적값의 크기가 커질 수 있습니다. 너무 큰 점수를 softmax에 넣으면 일부 값에 확률이 지나치게 몰리고 기울기가 작아져 학습이 어려워질 수 있습니다. 점수 크기를 조절해 학습을 안정화하려는 것입니다. 문장 길이의 제곱근으로 나누는 것이 아닙니다.

강의의 dk=64이면 √64=8입니다. 내적 128은 16, 내적 32는 4가 됩니다.

작은 숫자로 Attention 끝까지 계산

아래는 이해를 위한 보충 예제입니다. 한 query에 대해 계산하며 dk=1입니다.

Q = [1]
K₁ = [0], K₂ = [ln 3]
V₁ = [2,0], V₂ = [0,4]
  1. 내적 점수: [0, ln 3].
  2. √dk=1로 나누므로 그대로입니다.
  3. 지수값: [e⁰,e^(ln 3)]=[1,3].
  4. softmax 비율: [1/4,3/4]=[0.25,0.75].
  5. 가중합: 0.25[2,0]+0.75[0,4]=[0.5,3].

Q·K로 비율을 정하고 V로 결과 벡터를 만들었습니다. K와 V는 꼭 같은 숫자·차원을 가질 필요는 없습니다. 이 예시도 K는 1차원, V는 2차원으로 역할을 구분했습니다.

p. 38의 예시 비율은 정확한 softmax 계산값이 아닙니다

슬라이드에는 점수 [16,4,4,16] 뒤에 [0.4,0.1,0.1,0.4]가 제시되어 있지만, 실제 softmax는 약 [0.499997,0.000003,0.000003,0.499997]입니다. 슬라이드의 비율은 가중합을 설명하는 도식으로 구분하고, 직접 계산 문제에서는 지수 함수를 사용하세요.

행렬 크기: 객관식으로 나오면 차근차근

출처: Transformer pp. 36~39. n=4인 문장에 강의의 512·8 설정을 적용했습니다.

단계행렬 곱결과 크기
입력 X단어 4개, 각 512차원4×512
WQ, WK, WV512차원을 64차원으로 변환각 512×64
Q, K, V(4×512)(512×64)각 4×64
KᵀK의 행·열 교환64×4
QKᵀ(4×64)(64×4)4×4
Attention 비율 A스케일링 후 행별 softmax4×4
한 head의 출력 AV(4×4)(4×64)4×64

4×4 비율 행렬은 단어 4개 각각이 다른 4개를 얼마나 참고하는지 담습니다. 4×64 head 출력은 참고를 마친 단어별 새 표현입니다. 둘은 다른 행렬입니다.

Multi-head: 여러 관점으로 참고하기

출처: Transformer pp. 40~46.

한 명의 독자가 보는 관계와 여러 독자가 보는 관계가 다를 수 있습니다. Multi-head는 각 head가 서로 다른 학습 가중치로 Q·K·V를 만들어 Attention을 병렬로 수행합니다. 문법·지시 관계 등 여러 관계를 담을 수 있지만, head별 역할을 사람이 미리 지정하는 것은 아닙니다.

headᵢ = Attention(XWᵢQ, XWᵢK, XWᵢV)
MultiHead = Concat(head₁, …, head_H)WO
  1. 같은 입력 X로 8개의 서로 다른 Q·K·V 세트를 만듭니다.
  2. 각 head는 64차원의 공간에서 Attention을 수행합니다.
  3. head 출력 8개를 옆으로 연결(concat)합니다.
  4. 출력 가중치 WO를 곱해 합쳐진 정보를 변환합니다.
한 head 출력: 4×64
8개 연결:    4×(64×8) = 4×512
WO:          512×512
최종 출력:   (4×512)(512×512) = 4×512

처음 들어온 X도 4×512, 끝난 결과도 4×512입니다. 모양은 유지되고 내용은 바뀝니다. 그래야 다음 층에 같은 폭으로 전달하고 입력과 덧셈도 할 수 있습니다.

오답 선지 구분

  • ‘같은 Attention을 같은 가중치로 반복’ → 틀림. head별 가중치가 다릅니다.
  • ‘head가 8개면 문장도 8개로 나눔’ → 틀림. 각 head가 같은 시퀀스의 관계를 봅니다.
  • ‘head 출력을 평균내서 합침’ → 강의 구조는 concat 후 출력 변환입니다.
  • ‘Self-Attention과 Multi-head는 반대 개념’ → 틀림. 출처와 병렬 구조라는 서로 다른 기준입니다.

스스로 확인

Q. d_model=256, head=8이면 한 head의 d_k는?

강의처럼 균등하게 나누는 설정에서 256/8=32입니다.

Q. 토큰이 6개이면 Attention 비율 행렬은?

한 self-attention head에서 6×6입니다. d_model이 아니라 토큰 수끼리 비교합니다.

Q. Self-Attention은 자기 단어만 참고하므로 문맥을 알 수 없다. O/X?

X. 같은 시퀀스의 다른 토큰도 참고하므로 문맥을 반영할 수 있습니다.
