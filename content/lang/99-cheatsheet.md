# 핵심 암기 치트시트 + 연습문제

시험 직전 30분용. 7주차 복습 강의 「지금까지 나눈 이야기」의 15개 항목을 뼈대로 **선다형·단답형에 나올 만한 것**만 모았습니다.

## 전체 흐름 한 줄

> **사회언어학(언어 × 사회) → 지금 시대의 대화(맥커뮤니케이션·보이스피싱·AI) → 언어 능력과 세대 → 언어는 본능인가(핑커 vs 크리스티안센&채터) → 인식이 바뀌면 말이 바뀐다 → 언어가 다르면 생각도 다른가(사피어-워프)**

## 🔴 7주차 복습 강의(녹음) 추가분 — 슬라이드에 없던 것

> 마지막 정리 강의에서 교수님이 **말로만** 덧붙인 내용입니다. 슬라이드 정리에는 없으니 여기서 확인하세요.

| 항목 | 내용 |
|---|---|
| **시험 구성** | **단답형 5 + 선다형 13 + 서술형 1 = 19문항, 35점 만점**. 복습 강의에서는 "객관식"이라고만 했지만 **서술형 1문항 포함**. "**거기 안에 다 있습니다**" → 선다형은 보기에 단서 많음. 단 "문제 낼 게 너무 많다" → **범위 좁게 찍지 말 것** |
| **결정적 시기** | 만 **11~12세**면 뇌가 굳어 새 언어 습득이 매우 어려움 |
| **제1언어 vs 외국어** | 모국어는 **고통 없이** 습득(=본능의 증거) / 외국어는 고통스러움 → **습득 방식이 다름** |
| **완벽한 이중언어자** | **존재하지 않는다** (언어학자들의 연구 결론). 유럽 언어끼리는 **서로 비슷해서** 자동 습득되는 측면 |
| **『빈 서판』** | 핑커의 다른 책. **"인간은 백지로 태어난다"는 통념을 반박** → 『언어본능』과 **같은 편**(선천주의) |
| **보편문법의 반례** | **한국어** — 주어(NP)를 생략해도 문장 성립("간다."), 영어는 `I` 없으면 비문. 집단 중심 문화. 촘스키 본인은 **중단**, 촘스키안들이 이어감 → **보편문법 추출은 성공하지 못함** |
| **1980년대 방송** | MBC 생방송에서 가수 **정수라**에게 **몸무게 공개** 벌칙(61.7kg) → 수치심으로 방송 중단. **35~40년 전** = "야만의 시대" → **인식은 생각보다 빨리 변한다** |
| **"저만 그런가요?"** | 혐오·방관의 언어. 문제의식을 드러내지만 **"저도 그래요"** 공감만 받고 **문제 해결로는 가지 않음** → 뒤에 숨는 구조 |
| **AI 대화 한계(강조)** | 부분 수정 요청에도 **전체를 새로 써 버림**(유연한 수정 전략의 부재). 사람은 안 쓸 **과한 칭찬·수식어**("핵심을 찔렀어") |
| **언어 능숙도 결론** | 시험 잘 친 사람 ≠ 대화 잘하는 사람. 교육은 **발음→어휘·문법**으로 정형화돼 **대화 기술이 빠져 있음**. 진짜 중요한 건 **대화하는 나로서의 정체성** + 대화 기술 |

{: .중요 }
> **선다형 함정 3개**
> - "누구나 노력하면 **완벽한 이중언어자**가 될 수 있다" → ❌
> - "**빈 서판**은 핑커의 주장이다" → ❌ (핑커가 **반박**하는 통념)
> - "촘스키는 **보편문법을 입증**했다" → ❌ (가설, 한국어 등 반례로 **미완성**)

## 헷갈리는 비교

| 비교 | A | B |
|---|---|---|
| 표준형 사용 | **상위 계층, 여성** | 비표준형: 노동 계층, 남성 |
| 피진 vs 크리올 | 피진: 두 언어 화자의 **혼성어**, 어휘=상층어·문법=하층어, 단순, 수명 짧음 | 크리올: 피진이 **모국어**로 정착, 아이들이 시제·부정 등 문법 보완 |
| 핑커 vs 채터 | **선천주의**, 보편문법 내장(hardwired), 생물학적 진화 | **문화적 진화론**, 즉흥연주·charades, 빠른 문화적 진화, 보편문법 불필요 |
| 언어 간 공통점의 원인 | 촘스키: **보편문법** | 채터 등: 공유하는 **인지적 제약**(기억·지각), 공통된 의사소통 문제 |
| 언어능력 ✗ / 지능 ○ | **실어증**(좌반구 손상), **SLI** | 언어능력 ○ / 지능 ✗: **수다쟁이·서번트·윌리엄스 증후군** |
| 은어 / 비어 / 속어 | 은어: 집단 내부, **사회적 방언** (꼰대, 띵작) | 비어: **낮춤** (대가리) / 속어: **저속·욕** (존맛탱) |
| 문화상대주의 vs 자문화중심주의 | 그 문화 사람의 시각, 보애스 | 내 문화를 **당연하게 여기는 것까지** 포함 |
| 언어상대주의 vs 사피어-워프 | 모든 언어는 **대등**·완전 | 언어가 **사고를 결정** (언어결정주의) |
| 언어상대성 vs 전문성 | 언어가 세계관을 만든다 | 어휘 차이는 **유용성·전문성**의 차이 (Clark & Clark) |
| 6.1 vs 6.2 vs 6.3 | 언어→사고: 색채 실험, 심상 왜곡 | 사고→언어: 피라항, 사모 / 영향 ✗: 착시 |
| 밈 vs 멀티페르소나 | 밈: mimesis+gene, 모방·패러디 | 멀티페르소나: multi+persona, **다중 자아**, 줄임말의 **숨김 기능** |
