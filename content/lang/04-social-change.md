# 4. 사회변화와 언어변화

5주차 「왜 그런 말을 써요?」. **사회 구성원의 인식이 바뀌면 단어가 바뀐다**(명칭 변화)는 것, 그리고 **디지털 세대의 말**(밈·줄임말)과 **혐오의 언어**가 어떤 심리를 드러내는지 다룹니다.

**수업 목표**
- 사회의 변화, 인식의 변화로 인한 언어 사용 양상을 이해한다
- 언어 표현의 **변이형**이 가진 의미와 기능을 이해한다
- 언어가 사용자의 생각을 어떻게 드러내는지를 안다

> **언어는 언어 사용자의 인식을 담아내는 그릇**

{: .참고 }
> 도입부(개인주의 그래프, 동사가 된 '어른')는 3주차 내용의 반복이라 [2장 6~7절](02-language-user.html)에 정리했습니다.

## 1. 인식의 변화에 따른 언어의 변화 ★★★

### '병신춤'

병신춤 (病身-)
: 민간에서 **지배계층인 양반의 부자유스런 신체 부위를 부각**하여 **해학적으로** 표현하는 모방춤. 극중 효과를 높이고 **계급사회의 불합리를 폭로**하고 **평등을 염원**하는 의미

- 근대 이후 널리 알린 사람: **공옥진(孔玉振, 1931~2012)** — 봉사춤, 곱사춤, 동물 모방춤을 무대에 올려 한국 예술의 서민적 면모를 보여줌
- 그러나 **장애인을 모독한다는 비판**이 커져 **병신춤 연행을 중단**
- '병신'이라는 말이 예전엔 아무렇지 않게 쓰였다 → 단지 '병든 몸'이라는 뜻일까? 어떤 의미가 더 포함되어 있나?

→ **사회 구성원의 인식 변화에 따라 바꾸어 사용하기로 한 언어 표현들**이 있음.

#### 인식은 생각보다 빨리 변한다 — 1980년대 공영방송 사례 ★★

> 7주차 복습 강의에서 교수님이 "오늘 아침에 찾았다"며 새로 든 사례. **'병신춤'이 왜 이상하지 않았는지**를 설명하는 배경입니다.

- **1980년대 후반(약 1987~89년), MBC 공영방송 생방송** 예능
- **룰렛판**을 돌려 벌칙을 수행하는 코너에서, 벌칙이 **여성 출연자의 몸무게 공개**
- 가수 **정수라**가 당황해 울 듯한 표정이었는데도 진행자가 강행 → 저울에 올려 **61.7kg** 공개, 다른 연예인들은 판에 자기 몸무게를 적게 함
- 너무 수치스러워 **방송을 그만두었다**는 이야기까지 전해짐
- 교수님 표현: **"야만의 시대"** — 그런데 **불과 35~40년 전**(2026년 기준)

{: .중요 }
> 이 사례의 결론 = **"사람의 인식은 생각보다 빨리 변한다."** 그런 시대였으니 **'병신', '불구자'** 같은 말이 이상하지 않았던 것. 명칭 변화 목록(장애인·간호사·수어 등)을 **"왜 바뀌었나"** 로 묻는 문제의 근거가 됩니다.

### 불구자 → 장애자 → 장애인 → 장애우 ★★

| 시기 | 명칭 | 의미 |
|---|---|---|
| **1970년대 이전** | **불구자(不具者)** | '**갖추지 못한** 사람' |
| **1980년대** | **장애자(障礙者)** | |
| **1980년대 후반부터** | **장애인(障礙人)** | '**자(者)'보다 '인(人)'** 이 좀 더 대우한 느낌 |
| **2000년대 이후** (대중매체) | **장애우(障礙友)** | 벗? 친구? (← 교수님이 물음표를 단 부분) |

### 간호부 → 간호원 → 간호사 ★★

| 시기 | 명칭 | 의미 변화 |
|---|---|---|
| **1907년** 대한의원 간호부 양성소 설치 후 | **간호부(看護婦)** | '부(婦)' = 며느리·아내 등 **여성**을 뜻함 |
| **8·15 광복 이후** | **간호원(看護員)** | '부'→'원(員)': **직업인**으로 |
| **1987년 의료법 개정** | **간호사(看護師)** | '사(師)': **'선생'의 뜻**, **격을 높임** |

{: .시험 }
> **언어는 언어 사용자가 속한 사회 구성원들의 가치관을 반영한다.**
> 연도 짝: 간호부 **1907** / 간호원 **광복 이후** / 간호사 **1987 의료법 개정**
> 한자 의미 짝: 婦(여성) → 員(직업인) → 師(선생, 격 높임)

### 그 밖에 바뀐 말들

| 이전 | 이후 |
|---|---|
| 때밀이 | 세신사 → **목욕관리사** |
| 청소부 | **환경미화원** |
| 식모 · 파출부 · 가정부 | **가사도우미** |
| **수화(手話)** | **수어(手語)** |
| **국민학교** | **초등학교** |

- **수화 vs 수어**: 수화 = 손으로 말을 전하는 **의사소통 방식** / 수어 = **2016년 제정된 「한국수화언어법」** 에 따라 **한국어·영어처럼 동등한 자격을 가진 언어**로서의 의미
- **국민학교 → 초등학교**: **1941년 일본 왕의 국민학교령 칙서**에 의해 '국민학교'로 명명 → **1996년 3월 1일**부로 '초등학교'로 변경

{: .시험 }
> 수어 = **2016년 한국수화언어법** / 초등학교 = **1996.3.1** (국민학교 = **1941년** 일본 칙서)

## 2. "아니, 진짜 왜 그런 말을 쓰냐고요?"

- **'아니'**: 한국 사람들이 자주 쓰는 **담화 표지**. 화자가 **자신의 화제를 지속할 목적**으로 주로 사용
- **아니시에이팅(아니 + initiating)**: 게임 사용자들이 **남 탓을 시작한다**는 뜻으로 쓴 말, 주로 팀원들 사이의 **내분**이 일어날 때

## 3. 디지털 환경에 익숙한 세대의 언어 특성 ★★

### (1) 밈 (Meme)

- 그리스어 **'mimesis'(모방)** + **'gene'(유전자)** 의 합성어
- **『이기적 유전자』** 에서 문화 요소를 통해 다음 세대로 전파되는 **사상, 종교, 이념** 등의 의미로 사용
- 인터넷에서는 **문화적 모방 행위, 패러디**를 통해 널리 퍼지는 재미있는 사진·영상, 유행하는 단어·문구가 밈 언어로 사용
- **언어에만 한정되지 않음** (박순형 2022)
- 슬라이드 예: SBS 「그것이 알고 싶다」의 **"그런데 말입니다"**

### (2) 멀티페르소나 (Multi Persona)

- **'다양함(multi)' + '가면(persona)'** 의 합성어, **다중적 자아정체성**
- **줄임말 사용**: 디지털 환경에서 **빠르게 소통**하기 위한 목적 **외에도** **다 드러내지 않기 위한 목적**, 일종의 **숨김 기능**. **직설적 표현을 자제하고 유머러스한 방식**을 택하는 것이 특징 (박순형 2022)

{: .중요 }
> 줄임말을 쓰는 이유 = "빠른 소통" **만이 아니다!** → **숨김 기능(다 드러내지 않기)**, **직설 자제·유머**. 이게 **멀티페르소나**와 연결되는 포인트입니다.

## 4. 줄임말의 양상 (5유형, 박순형 2022) ★★

| 유형 | 예 |
|---|---|
| **(1) 앞음절만 딴 줄임말 — 의미 이해 필요 없음** | 구취(구독 취소), 빠태(빠른 태세 전환), 누물보(누가 물어보신 분?), 갑분싸(갑자기 분위기 싸해진다), 할많하않(할 말은 많지만 하지 않겠다), 쉽살재빙(쉽게만 살아가면 재미없어 빙고) |
| **(2) 앞음절만 딴 줄임말 — 의미 이해가 필요한 것** | 신꾸(신발 꾸미기), 깊꾸(기프티콘 꾸미기), 영끌(영혼까지 끌어모으다), 주불(주소 불러), 스불재(스스로 불러온 재앙), 닥눈삼(닥치고 눈팅 삼 개월), 핑프(핑거 프린스/프린세스), 갑통알(갑자기 통장을 보니 알바를 해야 한다), 좋댓구알(좋아요·댓글·구독·알림 설정) |
| **(3) 의미 이해가 필요한 줄임말** | 삼귀다(사귀기 전 썸 타는 관계), 오저씨(오빠와 아저씨 중간), 쫌쫌따리(아주 적은 양), 싫존주의(싫어하는 것을 당당히 밝히고 존중해 달라는 움직임), 업글인간(성공보다 성장을 추구하는 자기계발형 사람), 잼민이(초등학생이나 어린아이), 뇌절(똑같은 말·행동 반복) |
| **(4) 합성 방식의 새로운 단어** | 고스팅(잠수 타는 행위), 롬곡(눈물을 뒤집어쓴 형태), 갓수(일하지 않고 잘 사는 사람), 갓생(부지런하고 모범이 되는 인생), 있어빌리티(있어 보이게 포장하는 능력), 횰로(혼자만의 행복을 중시하는 생활방식), 쌉가능/쌉에이블/쌉파서블(강조), 머선129(무슨 일이야), ASKY(애인이 안 생겨요) |
| **(5) 탈경계성(trans-boundary) 방식의 단어** | 뒤 단어를 강조하는 접두사 **'킹-'** (킹받네, 킹정, 킹리적 갓심), **'어쩔티비'**('어쩌라고 가서 TV나 봐') → 어쩔냉장고, 어쩔에어컨 |

{: .시험 }
> 유형 맞히기 예
> - '킹-', '어쩔티비' → **(5) 탈경계성**
> - 롬곡, 횰로, 있어빌리티 → **(4) 합성**
> - 잼민이, 뇌절, 삼귀다 → **(3) 의미 이해 필요**
> - 갑분싸, 할많하않 → **(1) 앞음절, 의미 이해 불필요** / 영끌, 스불재 → **(2) 앞음절, 의미 이해 필요**
>
> (1)과 (2)의 차이: 풀어 쓴 말만 알면 바로 이해되나(1), 풀어 써도 배경 맥락을 알아야 하나(2).

## 6. 은어, 비어, 속어 ★★

| 구분 | 정의 | 예 |
|---|---|---|
| **은어** | **특수한 집단·사회·계층**에서 **남이 모르게 자기들끼리만** 알도록 쓰는 말. **사회적 방언** | 양아치, 똘마니, 꼰대 / 띵작, 띵곡 |
| **비어** | **점잖지 못하고 천한 말**, 대상을 **낮추어 보거나 얕보아** 하는 말 | 대가리, 주둥이 |
| **속어** | **통속적으로** 쓰이는 **저속한 말, 욕** | 존맛탱, 존예, 졸귀탱 |

**은어·비어·속어를 사용하는 이유 (3가지)**
1. **욕구불만으로 인한 반항적 심리**
2. **수치심을 은폐하려는 심리**
3. **유희적 쾌감**을 맛보기 위한 수단

{: .중요 }
> **은어 = 숨기기(집단 내부용, 사회적 방언)** / **비어 = 낮추기** / **속어 = 저속·욕**
> 정의를 바꿔 넣은 보기가 나오기 좋습니다.

## 7. 혐오의 언어 — "세상은 불공평해" ★★

(이종임 외 2021, 온라인 커뮤니티 '에브리타임'의 혐오 표현 연구)

### 원인

- **사회적 불평등, 불공정, 그리고 능력주의 이데올로기**가 청년 세대의 **분노 감정**과 결부 → **차별의 정당화**라는 이데올로기적 기제로 활용 → **혐오 표현 사용**
- 특정 집단에 기회가 주어지면 **'불공정'과 '역차별'** 을 주장, **상대적 박탈감**
- **자산 분배 문제, 무한경쟁**으로 인한 공정성 이슈 → **세대 갈등, 20대 남녀 갈등**
- **능력주의**가 노력에 대한 정당한 보상을 보장하는 개념으로 통용 → **노력 없는 보상에 민감**해짐 → 경멸과 혐오를 정당화할 위험

### 혐오의 표출 방식

- **차별받아 마땅하다**고 하는 **약자에 대한 분노**
- **평가절하를 통한 상대의 무력화**
- **정당한 차별과 정당한 혐오 인식의 공고화**

### 대상과 확산

- **비정규직, 고졸, 전문대, 지방대 출신** 취업자를 향한 혐오 표현
- **성소수자, 페미니스트** 혐오 — 성소수자를 페미니즘의 적으로 규정하고 배제하는 **모순적 상황**으로 귀결되기도
- **익명성**을 바탕으로 한 온라인 미디어 환경 → 혐오 표현 **확산 및 증식**
- 비난의 주체가 **우위**를 점하고 **확신과 쾌락**을 기반으로 디지털 공간에서 **감정적 유대 강화**
- **감정적 유대만 확인하고 문제 해결로는 가지 않음** ★ — 교수님이 직접 싫어한다고 밝힌 표현이 **"저만 그런가요?"**
  - 문제의식을 드러내는 말인데, 돌아오는 반응은 **"저도 그래요"** 뿐이고 **아무도 해결에 나서지 않음**
  - 공감 표명 뒤에 **숨어버리는** 방관의 구조

## 8. 타인을 평가하는 말 ★

> 타인을 **드세다**고 부르는 것은 **자기 고백**에 가깝다. "여자가 저렇게 드세면…", "어린놈이 당돌하네.", "쪼끄만 게 맹랑한 소리를 하네." 등은 상대가 내 마음대로 되지 않는 것을 씁쓸함과 비통함, 그리고 악의를 담아 복수하듯 이르는 소리다. 남을 **'드세다, 당돌하다, 맹랑하다'** 고 부를 정도의 **권력이 나에게 있다고 생각한다는, 혹은 그런 권력을 선언하고 싶다는 무의식의 목소리**다. 누군가가 나를 **'싸가지가 없다'** 라고 평가하는 것은 그가 **나의 위계를 그의 것보다 낮게 보았다는 실토**나 다름없다. (허새로미 2019: 89)

(건방지다, 사납다 등도 같은 부류)

### 꼰대

- 사전적 의미: ① 은어로 **'늙은이'** ② 학생들의 은어로 **'선생님'**
- 어떤 사람이 꼰대인가? 어른답지 못한 사람? **어른 대접을 일방적으로 요구**하는 사람? **젊은 꼰대**도 있음
- **꼰대인가 아닌가의 판단은 본인이 아니라 상대방에게 달림** → 상대가 알려주지 않는 이상 **본인은 자신이 꼰대인지 모름**

## 9. 무심코 사용하는 차별의 언어 ★ (김지혜 2019, 『선량한 차별주의자』)

### '결정장애'

- '장애'의 사전 의미: 신체기관이 본래의 제 기능을 하지 못하거나 정신 능력이 원활하지 못한 상태
- > "무언가에 **'장애'를 붙이는 것은 '부족함, 열등함'을 의미**하고, 그런 관념 속에서 '장애인'은 늘 부족하고 열등한 존재로 여겨진다." (김지혜 2019: 6)

### 이주민에게 "한국 사람 다 되었네요."

- > "이주민들은 자신들이 한국에 아무리 오래 살아도 **우리는 당신을 온전히 한국인으로 생각하지는 않는다는 전제**가 깔려 있기 때문에 **모욕적**이라고 했다." (김지혜 2019: 9)

> 칭찬처럼 들려도 차별 — "한국 사람 다 되었네요" → **온전한 한국인으로 보지 않는다는 전제**
> '결정장애' → '장애' = **부족함·열등함**을 의미하게 만듦
