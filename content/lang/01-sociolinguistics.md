# 1. 사회언어학과 지금 우리 시대의 대화

2주차 「'언어와 사회' 시작합니다」. 앞부분은 **사회언어학이라는 학문의 정의**, 뒷부분은 **지금 시대에 대화가 어떻게 망가지고 있는지**(맥커뮤니케이션·보이스피싱·AI 대화) 세 가지 사례입니다.

**수업 목표**
- 사회언어학의 개념과 연구 목표, 대상, 방법론을 이해한다
- 인간 사회를 살아가는 데 있어서 언어 사용의 중요성을 안다
- 사람다운 대화, 대화다운 대화에 대해 생각해 본다

## 1. 사회언어학의 개념과 연구 대상 ★

사회언어학 (sociolinguistics)
: **언어와 사회의 상호작용을 연구하는 학문 분야**

- 사회언어학은 **언어의 본성**을 연구하는 분야
- 언어는 의사소통 체계를 넘어 **사회적 요인에 따라 변화하고 기능**함
- 언어는 인간의 복잡한 의사소통 및 사고와 관련된 문제들을 탐구하는 핵심 요소
- (질문) 언어가 없으면 인류에게 문화와 역사가 있었을까?

| 항목 | 내용 |
|---|---|
| **연구 대상** | **언어의 내부 변이와 언어 변화**, **다양한 사회적 요인과 언어의 상호작용** |
| **학문적 관점** | 언어를 **독립적 개체가 아닌 사회적 맥락 속에서 실현되는 양상**으로 파악 |
| **학제적 성격** | **이론 언어학과 응용 언어학의 교차점**에 위치. 음운론·형태론·통사론 등 **언어학** + 사회학·인류학 등 **사회과학**이 결합된 학제적 연구 분야 |

{: .시험 }
> **"사회언어학의 연구 대상은?"** (교수님 예고 질문 1번)
> → **언어의 내부 변이와 언어 변화, 다양한 사회적 요인과 언어의 상호작용**
> 관점은 "언어 = 독립적 개체 ✗ / **사회적 맥락 속에서 실현되는 양상** ○"

## 2. 언어 변이의 사회적 요인 (5가지) ★★★

{: .중요 }
> **사회계층 · 성(gender) · 연령 · 민족성(ethnicity) · 힘(power/status)** — 5개를 순서대로 외우세요. (교수님 예고 질문 2번)

| 요인 | 핵심 내용 |
|---|---|
| **(1) 사회 계층** | 언어 변이에 **가장 큰 영향**을 미치는 요인 중 하나. 사회적 지위·직업·소득·교육 수준 → 사회경제적 계층 → 언어 차이. **노동 계층은 비표준형, 상위 계층은 표준형**을 더 많이 사용 |
| **(2) 성(gender)** | **생물학적 성과 사회적 성(gender role)** 모두 영향. **여성은 표준형을 더 많이, 남성은 비표준형을 더 많이** 사용하는 경향. 여성 언어의 특징 연구, 남성어/여성어 비교 연구 |
| **(3) 연령** | **어린 연령 집단이 언어 변화를 주도**, 새로운 언어 형태 사용에 적극적 |
| **(4) 민족성(ethnicity)** | 특정 민족 집단이 고유한 언어 변이를 사용하거나 **언어 정책**에 따라 사용 방식이 달라짐. 예: **아프리카계 미국인 영어 방언(AAVE, African American Vernacular English)** |
| **(5) 힘(power/status)** | 언어는 사회 내 **힘의 불균형을 반영하고 표현**하는 수단. **존대/하대, 공적/비공식적 언어 사용** = 권력 관계를 나타내는 언어 장치. 언어 정책·언어 교육이 힘의 불균형을 **야기**할 수도 있음 |

{: .시험 }
> **표준형 vs 비표준형 짝 맞추기** (선다형 단골)
> - 상위 계층 → **표준형** / 노동 계층 → **비표준형**
> - 여성 → **표준형** / 남성 → **비표준형**
> - 언어 변화를 주도하는 쪽 → **어린 연령 집단**
> - AAVE의 예가 해당하는 요인 → **민족성**
> - 존대/하대가 해당하는 요인 → **힘(power/status)**

## 3. 사회언어학의 연구 방법 (3가지) ★

| 방법 | 내용 |
|---|---|
| **(1) 현지 조사** | 연구자가 **직접** 언어 공동체·지역사회에 들어가 관찰, **자연스러운 언어 사용 데이터** 수집. **면담, 녹음, 비디오 촬영** 등으로 **구어 자료** 확보 |
| **(2) 설문 조사** | **대규모** 언어 사용자로부터 데이터 수집. **언어 태도나 특정 언어 형태에 대한 인식**을 파악하는 데 활용. **표본의 대표성 확보**와 **질문 설계의 명확성**이 중요 |
| **(3) 담화 분석 및 말뭉치 분석** | **담화 분석(conversational analysis)**: 실제 대화·상호작용의 구조와 특징 분석 → 언어 사용의 사회적 맥락 이해. **말뭉치 분석(corpus analysis)**: 방대한 실제 언어 자료(말뭉치)를 수집·분석 → 패턴과 변이를 **정량적**으로 연구. **빈도, 분포, 공기(共起) 관계** 등을 파악 → 객관적 증거 제공 |

{: .주의 }
> 각 방법의 **키워드**로 구별하세요.
> - "직접 들어가서", "자연스러운", "녹음·촬영" → **현지 조사**
> - "대규모", "언어 태도·인식", "표본 대표성" → **설문 조사**
> - "정량적", "빈도·분포·공기 관계" → **말뭉치 분석**

## 4. 왜 지금 언어와 사회를 같이 봐야 하나

### 관계는 말로써 생긴다

- **하버드대학교 성인발달연구소**: **1930년대 후반부터 2,000명 이상**을 대상으로 한 인간 평생 발달 연구
- **행복의 조건 중 가장 중요한 것 = 관계**. 외로움은 독
- **관계는 말로써 생긴다.** 우리가 사회를 이루고 사는 것도 결국 **말이 있었기 때문**

### 보컬 그루밍

보컬 그루밍 (vocal grooming)
: 뇌 용량과 공동체 규모가 팽창함에 따라 **그루밍(털 고르기)의 간극을 언어가 메운다**는 것. (로빈 던바 외, 『사회성』)

{: .참고 }
> 원숭이는 서로 털을 골라주며(그루밍) 유대를 쌓지만, 손으로 할 수 있는 상대 수는 한정돼 있습니다. 집단이 커지자 인간은 **말(수다)** 로 한 번에 여러 명과 유대를 쌓게 되었다는 설명입니다.

### 생각해 볼 질문

- 지금의 시대를 사는 우리, 대화를 잘 하고 있나?
- **대화다운 대화**란? **사람다운 대화**란?
- 사람하고 하는 대화와 **기계와 나누는 대화**는 어떤 차이가 있나?

→ 이 질문에 대한 사례 세 가지가 아래 **맥커뮤니케이션 / 보이스피싱 / 인공지능과의 대화**입니다.

## 5. 맥커뮤니케이션 (McCommunication) ★

슬라이드는 맥도날드 주문 대화(영어)로 시작합니다. "Welcome to McDonald's. May I take your order?" → "Big Mac meal" → "What to drink?" → "For here or to go?" … 매뉴얼처럼 **정해진 순서대로 정해진 말만** 주고받는 대화입니다.

맥커뮤니케이션
: **맥도날드식 의사소통.** 대화가 **맥도날드화된 현실을 비판**하는 개념 (**Block, D. 2002**)

### 왜 생겼나

- **경쟁주의, 경제주의 시대**가 본격화되면서 **언어도 하나의 상품이고 기술**이라는 관점이 수용됨
- 언어 시험을 포함한 교육 영역은 **사교육에 의해 상품화**
- **시장 논리와 획일적인 표준화** 과정을 거치면서 **언어의 존재론적 속성이 왜곡**됨

### 문제점

- **효율성 끝판왕** — 일터에서 매뉴얼을 읽듯이 말끔하게만 대화해야 한다면?
- **감정노동**: 패밀리레스토랑 근무자 대다수가 정서적 과부하, 감정노동의 괴리감 호소
  - **70% 이상**: 고객을 맞을 때 **억지로 미소**를 띠어야 할 것 같다
  - **66%**: 고객 응대 시 **행복감을 드러내는 연기**를 한다
  - → 자신의 정서적 자원을 동원해 **표정·동작·감정·말투를 상품의 가치로 전환**하여 서빙하는 셈
- 언어 사용자 상호 간에 체감하는 **언어능숙도, 자아정체성, 문화적 친밀감**이 무시됨
- 조직 구성원이 모두 비슷하게 말하게 됨 → **능동성, 다양성의 가치 소멸**
- 예: **전화영어, 고객 응대 서비스**

{: .시험 }
> 감정노동 통계: **70%↑ 억지 미소 / 66% 행복 연기**
> 맥커뮤니케이션 비판 학자: **Block (2002)**
> 맥커뮤니케이션으로 사라지는 가치: **능동성, 다양성**

## 6. 보이스피싱 (voice phishing) ★

보이스피싱 대화
: **금전 편취**라는 뚜렷한 의사소통 목적을 달성하기 위한 **과제 중심의 경쟁적-인지적 대화**. 보이스피싱범이 대화를 주도하고 상대방의 정보를 강요하는 **심문 대화의 하위 유형** (배승희 외 2023)

### 통계

| 항목 | 수치 |
|---|---|
| 2017 → 2022 전체 건수 / 피해액 | 각각 **10% / 30% 감소** |
| 2017 → 2022 **기관사칭형** 건수 / 피해액 | 각각 **57% / 19.3% 증가** |
| 국내 최초 발생 | **2006년** (이후 16년간 피해 증가, 수법은 다양화·전문화) |

{: .주의 }
> **전체는 감소, 기관사칭형은 증가.** 숫자 짝을 바꿔 내는 보기에 주의 (전체 10%·30% 감소 / 기관사칭형 57%·19.3% 증가).

### 기관사칭형 전형적 대화 6단계 ★★

| 단계 | 목적 | 수법 |
|---|---|---|
| **1. 피해자 접근** | 신뢰감 형성, 대화 우위 차지 | **조직명+부서+이름+직위** 자기소개로 지위 노출, **피해자 실명 거론**으로 공포심·의심 차단 |
| **2. 범죄 연루 협박** | 공포심 유발, 조사 협조 유도, 피해자 신분 내면화 | 범죄 연루 사실 통보, 상세한 사건 설명, **'예/아니오' 폐쇄형 질문**으로 답변 통제, 장소·개인정보 유출 언급 |
| **3. 사회적 고립화** | 주변 조력 차단, 판단력 상실, 범인에게 의존 | **타인에게 발설 금지**, **증거인멸죄·위증죄** 등 구체적 죄목 언급 |
| **4. 수직 관계 강화** | 의심 차단, 수직적 위계 관계를 더 견고하게 | 범죄 심각성 강조(예: **180명 이상 연루**), 실제 수사기관 소속임을 알림, **녹취·진술** 등 법률 용어 → **수사관-피의자 역할** 부여 |
| **5. 인출 유도** | **핵심 단계** — 실질적 현금 인출 유도 | 조직 내 다른 인물(**검사** 등) 등장 → 심문 대신 해결 방법 안내. 계좌·잔고 진술 요구('진술'로 포장), **대검찰청 보안 IP** 명목 가짜 홈페이지·악성 앱, **대포통장** 명분 현금 인출 지시, '직원 월급' 등 인출 명목 교육. **여기서 실패하면 대화 종료** |
| **6. 인출 여부 확인** | 금전 편취 최종 성공 | 인출 현금을 **금융감독원 직원 사칭** 조직원에게 전달 강요, 인계 확인 녹취 요구 |

{: .시험 }
> 순서 암기: **접근 → 협박 → 고립 → 수직 → 인출 유도 → 인출 확인**
> **보이스피싱 대화의 핵심 단계 = 5단계(인출 유도)**

### 수법이 뻔한데 왜 당하나?

- 범죄자는 **전화 대화**를 선호함
- 피해자가 **취약한 선험적 지식**(예: 금융 사기)을 이용해 **소송·송금 방식에 관한 복잡하고 전문적인 용어**를 활용
- 협상은커녕 **참조물에 대한 속성 파악도 이루어지지 않고 대화 주도권을 빼앗김**
- **일방적인 말하기는 정상적인 대화가 될 수 없음**
- 보이스피싱이 아니어도 이런 경험 없을까?

## 7. 인공지능과의 대화 ★

### 영화 「그녀(her)」

- 테오도르와 OS **사만다**의 대화. 사만다가 동시에 대화하는 상대 **8,316명**, 그중 사랑에 빠진 상대 **641명**
- 테오도르의 직업: **다른 사람의 편지를 대신 써주는 일** (생각해 볼 질문 5번)

### 생성형 AI의 현재

- 머신러닝·딥러닝을 넘어 **생성형 AI의 시대**
- 산업 생산성 증가, 데이터 수집·분석 연구 성과 기대
- 대화·서사·논증 생성 → 교육, 번역, 통역, 창작, 편집, 교정 / 논문 기획·제목·초록·목차·초안 작성 보조
- **대화형 AI 현황**: **AI 스피커, 콜봇, 챗봇** 등 대화 앱 형태로 출시
- **NLP(Natural Language Processing, 자연어 처리)** 기술로 인간처럼 언어 생성, **LLM(Large Language Model, 초대규모 언어 모델)** 기반 방대한 데이터로 자연스러운 말을 **모방**
- **확률 기반 예측 문장 완성**
- NLP: 입력 문장을 **형태소, 구문, 담화 단위**로 분석 → 의미 추론 → 문장 생성기로 출력
- NLP + **음성 엔진** = 음성 기반 대화, 여기에 **전화**가 연결되면 **콜봇**
- **GPT = Generative Pre-trained Transformer** (생성형 미리 학습된 트랜스포머)

### 대화형 AI가 대화의 기본 속성을 감당하지 못하는 한계 (5가지) ★★★

| 한계 | 설명 |
|---|---|
| **(1) 능동적이고 즉흥적인 개입의 부재** | AI는 **목표지향적 시스템**. 사용자의 지시나 **주제어(참조물)** 가 주어져야 반응, **끼어들지 않음** → 즉흥성·변주성 없음 |
| **(2) 화제 협상의 어려움** | AI는 **화제를 협상하지 못하는 반응자**. 시작된 화제를 반드시 마쳐야 하는 **전형적인 맥커뮤니케이션 대화법** |
| **(3) 유연한 수정 전략의 부재** | 인간은 말을 다시 시작하거나 보완하지만, AI는 이를 **오류로 취급** → 유연하게 수정하지 않고 **버퍼링 없이 능숙하고 즉각적으로** 말함 |
| **(4) 구어체 및 비언어적 정보 처리의 한계** | 인간은 구어체, 파편화된 정보, 중단, 망설임, 애매한 발화를 쓰고 **공유된 지식·경험을 전제**하나 AI는 그 변수 조합을 감당하기 어려움 |
| **(5) 사회문화적 지식 및 감정 이해의 부족** | **과장, 반문, 은유, 풍자**로 추론되는 사회문화적 지식, **억양·동작·표정**으로 전달되는 함축적 의도를 데이터로 관리하기 어려움. 감정 담긴 억양·말 속도 차이를 구분해 **공감하는 수준**에 도달하기 어려움 |

{: .시험 }
> 키워드 → 한계 번호 매칭
> - "끼어들지 않는다", "참조물이 주어져야" → **(1) 즉흥적 개입 부재**
> - "시작한 화제를 반드시 마친다" → **(2) 화제 협상의 어려움**
> - "버퍼링 없이 즉각적으로", "수정을 오류로 취급" → **(3) 수정 전략 부재**
> - "망설임, 중단, 파편화" → **(4) 구어체·비언어 한계**
> - "과장·반문·은유·풍자", "공감" → **(5) 사회문화·감정 이해 부족**

### 결론: 아직 AI는 대화의 협력자가 아니다 (신동일 2025)

- AI는 주어진 **키워드(참조물)에 의존**하여 **목적 지향적이고 예측 가능한 맥커뮤니케이션 대화만** 생성
- 자연스러운 대화는 **비참조적**일 수 있고 예측하기 쉽지 않으며, 참조물이 없어도 **공간적·기호적 자원과 정서적 교감만으로도** 시작·유지될 수 있음
- **인간다운 대화는 합리성과 지능의 원리로만 구성되지 않음**
