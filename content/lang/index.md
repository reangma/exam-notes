# 언어와 사회

중간고사 범위(1~7주차) 강의 자료 7개를 **빠짐없이** 옮기고 다시 정리한 노트입니다.

{: .중요 }
> **시험 정보**
> - **중간고사: 10월 21일 (8주차)** — 중간 35점 / 기말 35점 / 출석 5 / 조별활동 20 / 동료평가 5
> - **문제 구성(확정): 단답형 5문항 + 선다형 13문항 + 서술형 1문항, 35점 만점** — 총 **19문항**
>   - **서술형이 1문항 있습니다.** 복습 강의에서 교수님은 "객관식"이라고만 말했지만, 실제 출제는 서술형을 포함합니다
>   - **단답형 5문항** → 용어·인물·개념을 **직접 쓸 수 있어야** 함 (고르는 게 아님)
>   - **선다형 13문항** → 교수님 말로 **"거기 안에 다 있습니다"**, **"답이 보일 수도 있고"** = 보기에 단서가 있는 문제가 많을 것
> - 배경: 교수님은 원래 인문계열 과목을 **모두 논술식**으로 출제했는데, 이번 학기는 **수강생이 많아** 객관식 비중을 크게 늘렸습니다 (**"처음이에요"**)
> - **"문제 낼 게 너무 많다"** 고 했으므로 **범위를 좁게 찍지 말 것** — 복습 강의에서 다룬 전 범위가 사정권
> - 출석 ¼ 이상 결석 시 F

## 이 과목이 결국 하려는 이야기

> **언어는 사회를 비추는 거울이다.** 사람이 사는 방식(세대·가치관·문화·환경)이 바뀌면 말이 바뀌고, 거꾸로 말은 우리가 무엇에 주목하고 어떻게 기억하는지에 영향을 준다.

| 강의 | 핵심 질문 | 키워드 |
|---|---|---|
| 2주 언어와 사회 | 사회언어학이란? 요즘 대화는 왜 대화답지 않나? | 변이 요인 5, 연구방법 3, 맥커뮤니케이션, 보이스피싱 6단계, AI 대화 한계 5 |
| 3주 언어와 언어 사용자 | 왜 그렇게 말해요? (세대) | ACTFL 5등급, 대화의 기능 5, 트웬지 세대론, '어른'의 동사화, 3요 |
| 4주 마음이 언어를 만드는 방법 | 언어는 본능인가? | 핑커 증거 4, 보편문법, 피진·크리올, 크리스티안센&채터의 반박 |
| 5주 사회변화와 언어변화 | 왜 그런 말을 써요? | 장애인·간호사 명칭 변화, 밈, 멀티페르소나, 줄임말 5유형, 혐오 표현 |
| 6주 언어와 문화 | 무엇이 달라서 달라요? | 문화상대주의, 언어상대주의, 사피어-워프, 언어↔사고 3경우 |
