# 4. RPi를 위한 전자회로 기초

## 전기회로의 기본

배터리와 전구를 전선으로 연결하면 배터리의 **전기에너지 → 빛에너지**로 전환된다.

- **전구**: 전기에너지를 소모하므로 **부하**, 전류의 흐름을 방해하므로 **저항**이라고 할 수 있음
- **열린 회로(open circuit)**: 전선이 중간에 끊어져 **전류가 흐를 수 없는** 회로
- **닫힌 회로/폐회로(closed circuit)**: 전선이 연결되어 있는 회로. **전기회로 = 닫힌 회로**

---

## 전류 · 전압 · 저항

| 구분 | 기호 | 단위 |
|---|---|---|
| 전압 | **V** (voltage) | **V** (볼트) |
| 전류 | **I** (intensity) | **A** (암페어) |
| 저항 | **R** (resistance) | **Ω** (옴) |

**전류(current)**
: 전선을 통해 흐르는 전기의 양. (+)와 (−) 성질을 띠는 입자를 **전하**라 하고, 전하의 이동이 전류를 만든다.

{: .시험 }
> **전류는 (+)극에서 (−)극으로 흐른다** — 이는 **전자의 흐름과 반대 방향**이다.
> 실제로 이동하는 것은 (−)전하를 띠는 **전자**이며, 전자는 **(−)극에서 (+)극으로** 이동한다.

**전압(voltage)**
: 전류가 흐를 때의 힘, 즉 **전류의 압력**. 전류는 **전압이 높은 곳에서 낮은 곳으로** 흐른다.

**저항(resistance)**
: 전류의 흐름을 방해하는 요소

| 구분 | 설명 |
|---|---|
| **도체** | 저항이 작아서 전기가 잘 흐르는 물질 |
| **부도체** | 저항이 커서 전기가 잘 흐르지 않는 물질 |
| **반도체** | 도체와 부도체의 중간 물질 |

## 옴(Ohm)의 법칙

**1827년 독일의 물리학자 Georg Ohm**: 일정한 온도에서 도체를 흐르는 전류는 도체 양단의 전압에 **비례**한다.

```
V = I × R
```

전류는 **저항에 반비례**하고 **전압에 비례**한다. (`I ∝ V/R`)

> **예제**: 12V 배터리에 저항 6Ω → `I = 12V / 6Ω = 2A`

### 단선과 단락

| 용어 | 상태 |
|---|---|
| **단선 (open)** | 저항이 **무한대**라서 전류가 **흐르지 않는** 상태 |
| **단락 (short, 합선)** | 저항이 **0에 가까워** 높은 전류가 흐르는 상태 |

{: .주의 }
> 전기회로에서 **절대로 +선과 −선이 합선되지 않도록** +와 − 극 사이에 **저항이나 부품을 넣어야** 한다.

## 키르히호프(Kirchhoff)의 법칙

### 전류 법칙

폐회로의 **접속점(node)** 으로 들어오는 전류의 합 = 나가는 전류의 합

```
ΣI_in = ΣI_out
I1 + I2 + I3 = I4 + I5
```

**Node**: 회로에서 전선이나 저항 같은 부품들로 연결된 **교차점**

### 전압 법칙

폐회로의 **전원 전압의 합** = 폐회로 내의 **전압 강하의 합**

```
Vs = V1 + V2 = I·R1 + I·R2 = I(R1 + R2)
전체 저항 Rt = R1 + R2        (직렬)
```

{: .시험 }
> **계산 문제 유형**
>
> 12V 전원에 R1=10Ω, R2=20Ω, R3=30Ω 직렬 연결. 전류 I와 R2의 전압강하 V2는?
>
> ```
> 12V = I × (10 + 20 + 30) = I × 60Ω
> I = 0.2A
> V2 = I × R2 = 0.2A × 20Ω = 4V
> ```

### 저항의 병렬 연결

여러 저항을 여러 줄로 연결하는 것. **전체 저항의 굵기가 굵어지는 효과**가 나서 **전체 저항은 작아진다**.

```
1/R = 1/R1 + 1/R2        (전체 저항)
V  = V1 = V2             (전압은 모두 같음)
I  = I1 + I2             (전류는 합 — 키르히호프 전류 법칙)
```

> **예제**: 2Ω에 5A, 5Ω에 2A가 흐르면 전체 전류는 **7A**.
> 전류는 **저항에 반비례**하여 나뉜다.

## 브레드보드

전자회로의 **임시 시제품**을 만드는 데 사용하는 **재사용 가능한 무납땜 장치**.

- **양쪽 가장자리(A, D)의 `+` `−` 표시** → **전원**을 연결하는 곳 (세로로 연결)
- **가운데 부분(B, C)** → **가로로 5칸씩 연결**되어 있음. 여기에 전선·부품을 꽂아 회로 구성

## 저항 (resistor)

고정저항은 용량을 **표면의 색띠**로 표시한다.

### 4개 띠

| 띠 | 의미 |
|---|---|
| 1번째 | **십의 자릿수** |
| 2번째 | **일의 자릿수** |
| 3번째 | **10의 n승을 곱하는 배수** |
| 4번째 | **허용 범위(오차)** |

> **예**: `10 × 1000 = 10000Ω = 10kΩ ± 5%`

### 5개 띠

| 띠 | 의미 |
|---|---|
| 1번째 | **백의 자릿수** |
| 2번째 | **십의 자릿수** |
| 3번째 | **일의 자릿수** |
| 4번째 | **10의 n승 배수** |
| 5번째 | **허용 범위** |

## LED (light emitting diode)

**발광다이오드** — 전류가 흐르면 빛을 내는 **반도체 다이오드**.

- 용도: 제품이 켜지거나 동작 중임을 나타내는 **인디케이터(indicator)**
- LED를 여러 개 합쳐 만든 **FND**(flexible numeric display)는 **숫자 표현**용

### 극성

{: .중요 }
> **다리가 긴 쪽 = +극(anode)**, **짧은 쪽 = −극(cathode)**
> 기호에서 **삼각형 꼭대기에 `|` 기호가 있는 쪽이 −극**, 반대쪽이 +극

### 데이터시트 (datasheet)

**데이터시트** = 전자부품의 **사양(specification) 설명서**

| 항목 | 의미 |
|---|---|
| **Absolute maximum rating** | 제품의 **최대 정격**. 그 이하로 사용해야 안전하다고 제조사가 정해놓은 규격 |
| **Forward current (I_F)** | **순방향 전류** (+극 anode → −극 cathode). 예: 20mA 이하로 사용 |
| **Forward voltage (V_F)** | **순방향 전압**. 예: 전류가 20mA일 때 1.8V~2.2V |

### 저항값 계산 (시험 단골)

{: .시험 }
> **LED 보호 저항 구하기**
>
> 조건: 전원 5V, LED의 V_F ≈ 2V, 정격 전류 20mA
>
> ```
> 저항에 걸리는 전압 = 5V − 2V = 3V
> R = V / I = 3V / 0.02A = 150Ω
> ```
>
> → 저항은 **150Ω 이상**, 실제로는 **150Ω ~ 1kΩ** 정도를 선택

## 푸시버튼 스위치 (Tact 스위치)

Tact 스위치는 **4개의 핀 중 거리가 먼 핀들이 서로 연결**되어 있고, **스위치를 누르면 모든 핀이 연결**되는 구조.

## 콘덴서 (condenser / capacitor)

**축전기**라고도 하며 **전기를 저장할 수 있는 장치**.

- 내부에 **두 개의 도체판**이 마주보는 구조. 음극에 (−)전하, 양극에 (+)전하가 모여 전기에너지 저장
- **순간적으로 높거나 낮은 전압 잡음을 제거**하여 안정적인 전기 공급

### 직류 전원에서

- 전기에너지가 **저장(충전)되는 동안 전류가 흐르고**, 용량만큼 저장된 이후에는 **전류가 흐르지 않음**
- 외부 전압이 높을 때 충전 → 외부 전압이 콘덴서 내부 전압보다 낮아지면 **저장된 전류를 내보냄** → **직류 전기의 안정적 공급**
- 라즈베리파이는 초소형 PC이므로 **직류 전원** 사용

### 교류 전원에서

- +, −로 극성이 규칙적으로 변하므로 **충전과 방전을 반복**하면서 전류가 흐름
- **직류는 차단하고 교류는 통과**시켜 교류 전기의 안정적 공급

### 종류와 극성

- 필름·세라믹·오일 콘덴서 등 다양하지만 **전해 콘덴서가 가장 많이 사용**됨
- **극성이 있는 콘덴서**와 **없는 콘덴서**가 있음

### 용량 단위

**패럿(farad, F)** — 영국 물리학자 **마이클 패러데이**의 이름에서 유래

**1F**: 1V의 전위차를 걸어주었을 때 **1쿨롱(coulomb)의 전하를 충전**시키는 전기용량

| 단위 | 값 |
|---|---|
| 마이크로패럿 (μF) | 10⁻⁶ F |
| 나노패럿 (nF) | 10⁻⁹ F |
| 피코패럿 (pF) | 10⁻¹² F |

{: .참고 }
> **실습**: 콘덴서를 직류회로에 **병렬**로 연결 → 전압이 높을 때 충전, 떨어질 때 방전 → **전압을 안정시키는 백업 전원** 용도. 스위치를 잠깐 눌렀다 떼면 LED가 **서서히 꺼진다**.

## 트랜지스터 (transistor)

게르마늄·규소 등 **반도체를 이용해 전자신호 및 전력을 증폭하거나 스위치**하는 데 사용되는 반도체 소자.

### 3개의 다리 (밸브 비유)

| 핀 | 비유 | 역할 |
|---|---|---|
| **Collector (C)** | 밸브의 **물이 들어가는 입구** | 전류 유입 |
| **Emitter (E)** | 밸브의 **물이 나가는 출구** | 전류 유출 |
| **Base (B)** | 밸브를 **열어주는 손잡이** | 제어 |

밸브를 열면 **C → E로 전류가 흐른다**.

### 두 가지 기능

**증폭 기능**
: B에서 밸브를 조금만 돌려도 물(전류)이 많이 나옴

**스위치 기능**

| 상태 | 조건 | 모드 | 상태 |
|---|---|---|---|
| **ON** | B에 **작은 전류가 흐르면** C→E로 전류가 흐름 | **saturation(포화)** | **short** |
| **OFF** | B에 **전류가 흐르지 않으면** C→E로 전류가 흐르지 않음 | **cut-off(차단)** | **open** |

ON일 때 B→E로 흐르는 전류는 아주 작으므로 **C에서 E로만 전류가 흐른다**고 본다.

### 종류

| 종류 | 동작 |
|---|---|
| **NPN형** | **B → E**로 전류가 흐르면 **C → E**로 전류가 흐름 |
| **PNP형** | **E → B**로 전류가 흐르면 **E → C**로 전류가 흐름 |

## 다이오드 (diode)

**+극(anode) → −극(cathode)** 으로만 전류를 흐르게 하고 **반대로는 흐르지 않게** 한다.
(순방향으로는 잘 흐르고 **역방향은 막음**)

### 순방향 전압 (Forward voltage, V_F)

순방향으로 전류가 흐를 때 다이오드에서 **0.2V ~ 0.7V 정도의 전압 강하**가 일어난다.

> **예**: 5V 전원에 V_F = 0.7V인 다이오드를 순방향 연결 → 다이오드를 지난 후 **4.3V**

### 항복 전압 (Breakdown voltage, V_BR)

역방향 전압이 매우 크면 다이오드가 견디지 못하고 **역방향으로 전류를 흘리게** 되는데, 이때 걸리는 역전압.

### 데이터시트 읽기 (1N4148 예시)

| 항목 | 값 | 의미 |
|---|---|---|
| 순방향 전압 | 최대 약 **1V** | |
| **항복 전압** | **100V** | 100V 이상의 역전압이 걸리면 역방향으로 전류가 흐름 |
| **Forward continuous current** | **300mA** | 연속 사용 가능 전류. 이보다 큰 전류가 흐르면 **더 큰 전류를 견디는 다이오드로 교체** 필요 |
