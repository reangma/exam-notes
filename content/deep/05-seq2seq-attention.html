5. Seq2Seq와 Attention

출처: #3 Transformer.pdf pp. 2~23.

이 장의 이야기

긴 글을 번역할 때 작은 메모 하나만 보고 번역하면 내용을 놓치기 쉽습니다. 그래서 단어를 하나 만들 때마다 원문에서 필요한 부분을 다시 참고하게 만든 것이 Attention의 핵심 아이디어입니다.

순서가 중요한 데이터

출처: Transformer pp. 2~3.

문장·음성·시간에 따른 측정값처럼 앞뒤 순서가 중요한 데이터가 있습니다. ‘나는 너를 좋아해’와 ‘너는 나를 좋아해’는 같은 단어가 있어도 순서에 따라 뜻이 달라집니다.

  • RNN: 앞 단계의 상태를 다음 단계로 넘기며 순서대로 읽는 신경망.
  • Hidden state: 지금까지 읽은 정보를 담은 중간 상태 벡터.
  • LSTM·GRU: 오래된 정보를 더 잘 다루도록 RNN을 개선한 계열. 이 자료에서는 배경으로 등장합니다.

자료의 ‘가변 길이 한계’ 읽는 법

RNN 자체가 길이가 다른 입력을 전혀 못 받는 것은 아닙니다. 여기서 중요한 문제는 입력 문장과 출력 문장의 길이가 서로 다른 변환을 어떻게 구성할 것인가입니다. Seq2Seq가 인코더와 디코더를 분리하여 이를 다룹니다.

Seq2Seq: 읽는 역할과 쓰는 역할 나누기

출처: Transformer pp. 3~7.

Sequence to Sequence는 하나의 순서 있는 입력을 다른 순서 있는 출력으로 바꾸는 구조입니다. 강의 예시는 영어 I am a student를 프랑스어 je suis étudiant로 번역합니다. 입력은 4단어, 출력은 3단어로 길이가 다릅니다.

  1. Encoder(인코더): 입력 문장을 순서대로 읽습니다.
  2. Context vector(문맥 벡터): 입력 내용을 고정 길이의 벡터로 요약합니다. 기본 설명에서는 마지막 hidden state를 사용합니다.
  3. Decoder(디코더): 요약 정보를 바탕으로 출력 단어를 한 개씩 만듭니다.

LSTM 구현에서는 hidden state뿐 아니라 cell state도 전달할 수 있지만, 여기서는 강의의 문맥 벡터 설명에 집중하면 됩니다.

sos와 eos

토큰뜻역할
<sos>Start of Sequence생성을 시작하라는 표시
<eos>End of Sequence문장 생성이 끝났다는 표시
첫 입력 <sos> → je 예측
이전 출력 je   → suis 예측
이전 출력 suis → étudiant 예측
étudiant      → <eos> 예측 → 종료

이처럼 자신의 앞선 출력을 이용해 다음 출력을 만드는 방식을 자기회귀적 생성이라고 부릅니다. 위 설명은 생성 시점 기준이고, 학습 때 정답 이전 단어를 넣는 방식은 뒤에서 다룹니다.

글자는 계산할 수 없으니 숫자 목록으로

출처: Transformer p. 8.

임베딩(Embedding)은 단어·토큰을 숫자 벡터로 표현하는 것입니다. 예를 들어 student를 [0.2, −0.5, 0.7] 같은 벡터로 나타냅니다. 이 수치는 설명용이며 실제 값은 학습에 따라 달라집니다.

벡터의 각 숫자가 반드시 ‘나이, 성별’처럼 사람이 이름 붙인 의미와 일대일로 대응하지는 않습니다. 단어를 신경망이 처리할 수 있는 표현으로 바꾼다가 핵심입니다.

Softmax: 점수를 비율로 바꾸기

출처: Transformer p. 9.

softmax(z)ᵢ = e^(zᵢ) / Σⱼ e^(zⱼ)

분자는 지금 후보의 지수값, 분모는 모든 후보의 지수값 합입니다. 결과는 각각 양수이고 전부 더하면 1입니다. 큰 점수일수록 큰 확률을 받습니다.

보충 예시: 후보 점수가 [0, ln 3]이면 지수값은 [1,3], 전체 합은 4이므로 softmax는 [0.25,0.75]입니다. 점수 자체를 단순히 합으로 나누는 것과는 다릅니다.

디코더 출력은 보통 Dense(선형 변환)로 단어 후보별 점수를 만든 후 softmax로 확률을 구합니다. 강의에서는 확률이 가장 큰 단어를 고르는 예를 사용합니다.

기본 Seq2Seq의 두 문제

출처: Transformer pp. 10~11.

  1. 정보 병목: 문장이 길어져도 같은 크기의 문맥 벡터 하나에 모든 내용을 넣어야 하므로 중요한 정보가 손실될 수 있습니다.
  2. 기울기 소실: 긴 순환 계산을 거슬러 기울기를 전달할 때 값이 작아져 오래전 정보의 학습이 어려워질 수 있습니다.

두 문제는 관련이 있지만 같은 말은 아닙니다. 하나는 정보를 한곳에 압축하는 문제, 다른 하나는 학습 신호가 약해지는 문제입니다.

Attention: 매번 필요한 원문을 다시 보기

출처: Transformer pp. 11~20.

‘étudiant’를 만들려는 순간에는 원문의 student가 중요합니다. ‘suis’를 만들 때와 참고 비율이 달라질 수 있습니다. Attention은 매 출력 시점마다 인코더의 모든 hidden state를 비교하고, 관련된 부분에 큰 비중을 줍니다.

계산은 ‘점수 → 비율 → 가중합’

  1. 점수: 현재 디코더 상태 sₜ와 각 인코더 상태 hᵢ의 내적을 구합니다. eᵢ=sₜᵀhᵢ.
  2. 비율: 점수 목록에 softmax를 적용해 αᵢ를 구합니다. α들의 합은 1입니다.
  3. 가중합: 각 hᵢ에 αᵢ를 곱해 모두 더합니다. aₜ=Σᵢαᵢhᵢ.
  4. 연결: aₜ와 현재 디코더 상태 sₜ를 이어 붙입니다. [aₜ;sₜ].
  5. 예측: 연결 벡터를 변환하고 출력층·softmax를 거쳐 다음 단어를 예측합니다.

Concatenation(연결)은 더하기가 아니라 이어 붙이기입니다. [1,2]와 [3,4]를 연결하면 [1,2,3,4], 원소별로 더하면 [4,6]입니다.

가중합 계산 예제

보충 예시: 두 입력 상태가 h₁=[2,0], h₂=[0,4]이고 softmax 비율이 [0.25,0.75]라고 주어졌다고 합시다.

a = 0.25[2,0] + 0.75[0,4]
  = [0.5,0] + [0,3]
  = [0.5,3]

두 번째 정보가 더 큰 비율로 반영됩니다. 모든 벡터를 같은 비율로 평균내는 것이 아닙니다. 이 a는 숫자 하나가 아닌 벡터입니다.

Q, K, V는 질문·검색표·내용

출처: Transformer pp. 21~22.

도서관에서 책을 찾는다고 생각해봅시다.

  • Q(Query): ‘지금 어떤 정보가 필요하지?’라는 검색 요청.
  • K(Key): 요청과 비교하는 각 항목의 특징.
  • V(Value): 비율을 정한 뒤 실제로 가져와 섞는 내용.
역할이 장의 RNN 기반 Attention
Q현재 디코더의 hidden state
K인코더의 모든 hidden state
V인코더의 모든 hidden state
Attention(Q,K,V) = softmax(QKᵀ)V

Q와 K는 ‘얼마나 참고할지’를 결정하고, V는 실제로 섞을 정보입니다. 이 기본 예시는 K와 V에 같은 인코더 상태를 사용합니다. 다음 장의 Transformer에서는 서로 다른 학습 행렬로 K와 V를 만듭니다.

차이는 주로 연관성 점수를 계산하는 방식입니다. 우선 dot과 scaled dot의 차이를 확실히 이해하고 나머지는 구분해둡니다.

스스로 확인

Q. Attention score, weight, value는 각각 무엇인가?

Score는 연관성 원점수, weight는 softmax로 만든 참고 비율, attention value는 그 비율로 정보를 섞은 최종 벡터입니다.

Q. Attention은 인코더의 마지막 상태만 보는가?

이 장의 Attention은 인코더의 모든 시점 상태를 참고합니다. 마지막 벡터 하나에만 의존하는 병목을 완화합니다.

Q. Context vector는 항상 하나로 고정될까?

기본 Seq2Seq에서는 입력 요약 벡터 하나를 전달합니다. Attention에서는 디코더 시점마다 비율이 달라지므로 문맥 벡터도 달라질 수 있습니다.
