2. 신경망과 행렬 계산

출처: 2주차 PDF pp. 49~87, 93~95.

한 문장부터

신경망은 ‘입력에 가중치를 곱해 더하기 → 활성화 함수 통과’라는 작은 계산기를 여러 층으로 연결한 것입니다. 사람 뇌의 모든 동작을 그대로 복제한 것은 아닙니다.

뉴런 하나는 어떻게 계산할까?

출처: 2주차 PDF pp. 51~55, 58.

1. z = w₁x₁ + w₂x₂ + b    (가중합)
2. h = 활성화함수(z)         (값 변환)
3. h를 다음 층으로 전달

x는 재료, w는 재료별 양, b는 기본 간, 활성화 함수는 섞은 결과를 한 번 가공하는 규칙이라고 생각하면 됩니다. b도 학습하는 숫자입니다. 그림에서 입력이 1인 화살표에 가중치 b를 붙여 놓는 이유는 1×b=b이기 때문입니다.

단층 퍼셉트론과 XOR

출처: 2주차 PDF pp. 53~54.

단순 퍼셉트론은 가중합이 기준을 넘으면 1, 아니면 0을 내보냅니다. 여기서는 z>0이면 1, 나머지는 0이라는 규칙을 사용하겠습니다.

논리 연산뜻강의의 가중합
NOT0과 1 뒤집기z=−x+0.5
OR둘 중 하나라도 1이면 1z=x₁+x₂−0.5
AND둘 다 1일 때만 1z=x₁+x₂−1.5
XOR둘이 다를 때만 1단층 선형 경계로는 표현 불가

AND에서 입력 (1,0)이면 z=−0.5이므로 0, (1,1)이면 z=0.5이므로 1입니다.

x₁x₂ORANDXOR
00000
01101
10101
11110

XOR의 1인 점들은 대각선 양쪽에 있고, 0인 점들은 다른 대각선에 있습니다. 이 둘을 직선 하나로 분리할 수 없습니다. 은닉층과 비선형 활성화가 있는 다층 퍼셉트론은 여러 경계를 조합해 표현할 수 있습니다.

시험 답안용

단층 퍼셉트론은 선형 분리가 가능한 문제를 해결할 수 있지만 XOR처럼 선형 분리가 불가능한 문제에는 한계가 있다. 은닉층과 비선형 활성화 함수를 사용하는 다층 퍼셉트론은 비선형 관계를 표현할 수 있다.

입력층·은닉층·출력층

출처: 2주차 PDF pp. 55~61.

  • 입력층: 데이터가 들어오는 곳. 변수 3개면 입력 노드 3개.
  • 은닉층: 중간 계산과 특징 변환을 하는 곳. 층 수와 노드 수는 설계자가 정합니다.
  • 출력층: 답을 내놓는 곳. 무엇을 예측하느냐에 따라 형태가 달라집니다.

MLP(Multi-Layer Perceptron)는 다층 퍼셉트론입니다. Fully connected/Dense는 앞 층의 모든 노드와 다음 층의 모든 노드가 연결되는 방식을 말합니다. DNN은 여러 은닉층을 가진 깊은 신경망을 가리킵니다.

문제출력 예시
집값 하나 예측수치 1개를 내는 출력 노드 1개
서로 배타적인 동물 3종 분류softmax 확률 3개를 내는 출력 노드 3개
정상/불량 이진 분류sigmoid 출력 1개 또는 softmax 출력 2개로 설계 가능

슬라이드의 ‘출력 노드 수=범주 수’는 다중 클래스 softmax 설계를 기준으로 이해합니다. 회귀에서도 여러 수치를 동시에 예측하면 출력 노드가 여러 개일 수 있습니다.

활성화 함수가 필요한 이유

출처: 2주차 PDF pp. 94~95. p. 94에서 sigmoid와 ReLU가 손글씨로 강조되어 있습니다.

곱하고 더하는 일만 반복하면 여러 층을 쌓아도 하나의 선형·아핀 변환으로 합쳐집니다. 예를 들어 h=2x+1, y=3h+4면 결국 y=6x+7입니다. 중간에 비선형 변환이 있어야 복잡한 관계를 표현할 수 있습니다.

함수식·규칙특징
Sigmoidσ(z)=1/(1+e⁻ᶻ)출력 0~1, σ(0)=0.5. 양끝에서 기울기가 작아짐
tanh쌍곡탄젠트출력 −1~1, tanh(0)=0. 양끝에서 기울기가 작아짐
ReLUmax(0,z)음수는 0, 양수는 그대로
Leaky ReLUmax(az,z), 작은 양수 a음수 쪽에도 작은 기울기를 남김
ELUz≥0이면 z, z<0이면 a(eᶻ−1)음수 쪽을 부드럽게 변환
Maxout여러 선형 계산값 중 최댓값여러 후보 중 큰 값을 골라 비선형 표현

보충: ReLU는 양수 영역에서 기울기 1이라 sigmoid보다 기울기 소실을 줄이는 데 도움이 되지만, 음수 영역에서 계속 0을 출력하는 문제가 생길 수 있습니다.

sigmoid 미분은 출력값으로 다시 계산 가능

h = σ(z)
σ′(z) = h(1−h)

h=0.5 → 기울기 0.5×0.5=0.25
h=0.99 → 기울기 0.99×0.01=0.0099

출력이 0이나 1에 가까우면 기울기가 작습니다. 작은 수를 여러 층에서 계속 곱하면 앞쪽에 전달되는 기울기가 매우 작아질 수 있습니다.

sigmoid를 반대로 외우지 않기

sigmoid는 입력이 커질수록 출력이 1에 가까워지는 단조 증가 함수입니다. ‘큰 입력을 작은 범위로 압축’한다는 말을 ‘입력이 커지면 출력이 작아진다’로 이해하면 안 됩니다.

강의의 순전파 계산, 처음부터 끝까지

출처: 2주차 PDF pp. 62~63. 입력·가중치는 강의 그대로 사용하고 계산 결과는 식에 맞게 재계산했습니다.

입력은 x₁=2, x₂=3입니다. 은닉 노드가 2개, 출력 노드가 1개이며 모두 sigmoid를 사용합니다.

  1. 첫 은닉 노드 가중합: z₁=2×0.1+3×0.3+0.5=1.6.
  2. 첫 은닉 출력: h₁=σ(1.6)≈0.8320.
  3. 둘째 은닉 노드 가중합: z₂=2×0.2+3×0.4+0.6=2.2.
  4. 둘째 은닉 출력: h₂=σ(2.2)≈0.9002.
  5. 출력층 가중합: z₃=0.1h₁+0.2h₂+0.3≈0.56325.
  6. 최종 예측: ŷ=σ(z₃)≈0.6372.

원자료 숫자와 다른 이유

p. 62의 σ(1.6)=0.472, σ(2.2)=0.659 및 p. 63의 최종 수치는 표시된 sigmoid 공식과 맞지 않습니다. 이 노트는 공식으로 검산한 0.8320, 0.9002, 0.6372를 사용합니다. 시험에서 중간값을 따로 제공하면 그 조건을 따르고, 직접 계산하라는 문제라면 공식으로 계산합니다.

여러 뉴런 계산을 한 번에: 행렬 표현

출처: 2주차 PDF pp. 64~73.

h = σ(W₁x + b₁)
ŷ = σ(W₂h + b₂)

위 예시를 열벡터로 쓰면:
x  = [2]     W₁ = [0.1  0.3]     b₁ = [0.5]
     [3]          [0.2  0.4]          [0.6]

W₂ = [0.1  0.2]                 b₂ = [0.3]

σ는 벡터의 원소마다 적용합니다. 첫 줄의 h를 둘째 줄에 넣는 것은 앞에서 뉴런별로 했던 순전파와 같은 계산입니다.

행렬 크기 문제는 ‘다음 노드 × 이전 노드’

열벡터를 사용해 Wx로 계산할 때, 이전 층 노드가 a개이고 다음 층이 b개면 W는 b×a, 편향은 b×1입니다.

강의 구조: 10 → 20 → 10 → 3가중치 W편향 b출력 벡터
입력 10 → 은닉1 2020×1020×120×1
은닉1 20 → 은닉2 1010×2010×110×1
은닉2 10 → 출력 33×103×13×1

위 구조의 출처: 2주차 PDF pp. 74~85. 다음 파라미터 개수 계산은 이 구조를 활용한 연습입니다.

가중치 개수 = 20×10 + 10×20 + 3×10 = 430
편향 개수   = 20 + 10 + 3 = 33
총 학습 파라미터 = 463개

입력 노드에 따로 편향 10개를 더하지 않습니다. 계산을 수행하는 다음 층 노드마다 편향 하나입니다.

Transformer에서는 행벡터 표기가 나옵니다

이 장은 열벡터, Wx입니다. Transformer는 각 단어를 한 행에 놓고 XW로 계산합니다. ‘W는 무조건 다음×이전’이라고 외우기보다 곱셈의 안쪽 크기가 맞는지 확인하세요.

파라미터와 하이퍼파라미터

출처: 2주차 PDF p. 93.

  • 파라미터: 학습하면서 바뀌는 w와 b.
  • 하이퍼파라미터: 학습 방법·모델 구조의 설정. 은닉층 수, 노드 수, 활성화 함수 선택, optimizer 선택, 학습률, batch size 등.

학습률도 숫자이고 가중치도 숫자지만 역할이 다릅니다. ‘모델이 맞춰가는 값인가, 학습 방식을 정하는 설정인가’를 봅니다.

스스로 확인

Q. 입력 4개, 은닉 노드 3개면 W와 b 크기 및 파라미터 수는?

열벡터 표기에서 W는 3×4, b는 3×1, 총 12+3=15개입니다.

Q. ReLU(−2), ReLU(3), sigmoid(0)는?

차례로 0, 3, 0.5입니다.

Q. 활성화 함수 없이 선형 층을 많이 쌓으면 비선형 모델이 될까?

아닙니다. 여러 선형·아핀 변환은 하나로 합쳐집니다. 비선형 활성화가 있어야 복잡한 비선형 관계를 표현할 수 있습니다.
