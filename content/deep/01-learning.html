1. AI·데이터·머신러닝의 기본

출처: 심층학습_2주차_수업자료.pdf pp. 1~47, 49~50. 수업 운영 안내는 범위 표에만 반영하고, 아래는 개념 중심으로 정리했습니다.

한 문장부터

머신러닝은 예시 데이터를 보고, 입력과 정답 사이의 관계를 잘 설명하는 숫자들을 찾는 것입니다. 중고차의 주행거리·마력을 보고 가격을 예상하는 식을 학습하는 것이 한 예입니다.

AI, ML, DL은 서로 포함 관계

‘음식 안에 한식이 있고, 한식 안에 비빔밥이 있다’처럼 AI ⊃ ML ⊃ DL입니다.

이름쉬운 뜻구분점
AI, 인공지능사람의 지능이 필요한 일을 기계가 하게 하는 넓은 분야사람이 직접 정한 규칙을 사용하는 방법도 포함
ML, 머신러닝데이터에서 규칙·패턴을 학습하는 방법모든 판단 규칙을 사람이 일일이 쓰지 않음
DL, 딥러닝여러 층의 신경망으로 학습하는 방법입력의 유용한 표현도 함께 학습

표현 학습(Representation Learning)은 ‘무엇을 특징으로 볼지’도 학습하는 것입니다. 이미지에서는 입력에 가까운 층이 선·점 같은 단순한 특징을, 깊은 층이 더 복잡한 특징을 표현할 수 있습니다. 모든 깊은 층의 벡터 차원이 반드시 더 커진다는 뜻은 아닙니다.

강의의 역사 표시는 AI의 다트머스 회의(1956), 딥러닝 발전의 중요한 계기인 Hinton의 DBN(2006)입니다. 2006년 이전에 신경망이 없었다는 뜻은 아닙니다.

데이터: 숫자라고 다 같은 숫자가 아니다

출처: 2주차 PDF pp. 10~11, 17~18.

종류뜻예시
수치형·연속형연속된 양을 측정키, 무게, 온도
수치형·이산형셀 수 있는 값자녀 수, 제품 개수
범주형·명목형종류는 있지만 순서는 없음혈액형, 색상
범주형·순서형종류에 순서가 있음만족도 낮음·보통·높음

‘정상=0, 불량=1’이라고 저장해도 이것은 종류를 나타내는 번호이므로 범주형입니다. 숫자로 저장됐다는 이유만으로 회귀 문제가 되는 것은 아닙니다.

관측치, 변수, 정답 구분하기

  • 관측치(sample): 데이터 한 건. 중고차 한 대, 학생 한 명.
  • 변수(feature): 한 건을 설명하는 항목. 주행거리, 마력, 배기량.
  • 정답(label, target): 우리가 예측하려는 값. 중고차 가격.

차 100대의 특성 3개를 모으면 X는 보통 100행 3열입니다. 가격 y는 각 차마다 하나씩, 총 100개입니다.

전처리: 공부할 자료부터 제대로 만들기

틀린 답이 잔뜩 섞인 문제집으로 공부하면 잘 배우기 어렵습니다. 데이터도 분석하기 좋은 형태로 다듬어야 합니다.

문제쉬운 예시
결측치학생의 키가 비어 있음
이상치키가 1,700cm로 입력됨. 단, 드문 값이 모두 오류인 것은 아님
중복같은 거래가 두 번 들어감
불일치같은 무게를 어떤 행은 kg, 어떤 행은 g로 기록
잡음·편향측정값이 흔들리거나 특정 집단의 데이터에만 치우침

강의에서 언급하는 precision·accuracy는 데이터 품질 맥락에서 측정의 정밀도·정확도를 뜻합니다. 분류 성능 지표의 precision과 맥락을 구분합니다.

학습 종류는 ‘무엇을 알려주나’로 구별

출처: 2주차 PDF pp. 13~15.

학습 종류주어지는 정보공부 비유
지도학습입력 X와 정답 Y문제와 정답을 함께 보고 공부
비지도학습입력 X, 정답 없음비슷한 문제끼리 스스로 묶기
준지도학습일부만 정답 있는 데이터 + 정답 없는 데이터해설이 일부만 있는 문제집도 함께 활용
강화학습행동 결과에 대한 보상직접 해보고 점수가 좋아지는 행동 익히기

시험 답안용

지도학습은 입력과 정답을 이용하여 입력과 출력의 관계를 학습한다. 비지도학습은 정답 없이 데이터의 구조나 패턴을 찾는다. 준지도학습은 라벨이 있는 데이터와 없는 데이터를 함께 사용한다. 강화학습은 누적 보상을 크게 만드는 행동을 학습한다.

회귀와 분류: 정답이 ‘얼마’인가, ‘어느 종류’인가?

출처: 2주차 PDF pp. 17~27.

  • 회귀(Regression): 중고차 가격이 얼마인가? → 1,350만 원처럼 수치를 예측.
  • 분류(Classification): 이 제품이 양품인가 불량인가? → 어느 범주에 속하는지 예측.
  • 군집화(Clustering): 정답 범주를 주지 않고 비슷한 제품을 묶음. 비지도학습의 대표 예.

‘분류’와 ‘군집화’ 모두 묶는 느낌이지만, 정답 범주를 알려주고 학습하느냐가 다릅니다.

학습 데이터와 시험 데이터

출처: 2주차 PDF p. 16. validation 및 과적합 설명은 구분을 위한 보충입니다.

Training data는 모델을 가르치는 문제집, Test data는 다 배운 뒤 처음 풀어 보는 시험지입니다. 외운 문제만 잘 푸는지, 새로운 문제도 잘 푸는지 나눠 확인합니다.

일반화는 새로운 데이터에서도 잘 작동하는 것, 과적합은 학습 자료에 지나치게 맞춰져 새로운 자료에서 성능이 떨어지는 것입니다.

‘검증’이라는 단어 주의

슬라이드는 test data를 ‘검증 데이터’라고도 부릅니다. 실무에서 별도로 나누는 validation set은 설정을 고르는 중간 점검용이고, test set은 최종 평가용입니다. 테스트 정답을 보고 계속 설정을 고르면 공정한 최종 평가가 아닙니다.

모델은 계산 방식, 파라미터는 그 안의 숫자

출처: 2주차 PDF pp. 28~38, 47.

예를 들어 ŷ = w₁x₁ + w₂x₂ + b라는 형태를 골랐다고 해봅시다. 아직 w₁, w₂, b가 비어 있습니다. 데이터에 잘 맞는 w와 b를 찾는 과정이 학습입니다.

요리로 비유하면 모델 구조는 ‘재료를 어떤 순서로 조리할지’, 파라미터는 ‘각 재료를 얼마나 넣을지’입니다. 가중치는 음수도 될 수 있습니다. ‘중요도’라는 비유 때문에 항상 양수라고 생각하지 마세요.

오차를 그대로 더하면 안 되는 이유

예측이 한 번은 +3만큼, 다른 한 번은 −3만큼 틀렸다면 그냥 더한 오차는 0입니다. 하지만 두 번 다 틀렸습니다. 그래서 제곱해서 3²+(−3)²=18로 측정할 수 있습니다.

손실 함수(loss)는 예측이 틀린 정도를 수로 나타냅니다. 비용 함수(cost)는 여러 데이터의 손실을 합하거나 평균낸 것을 가리킬 때 많이 쓰며, 자료에 따라 두 용어를 혼용합니다. 강의의 ε는 원래 잔차이고, 이를 제곱·집계하여 최적화할 비용을 만듭니다.

선형회귀: 가장 잘 맞는 직선 찾기

출처: 2주차 PDF pp. 39~42.

예측: ŷ = w₀ + w₁x
비용: C = Σᵢ [yᵢ − (w₀ + w₁xᵢ)]²
목표: C가 가장 작은 w₀, w₁ 찾기

최소제곱법(Least Squares)은 ‘오차 제곱의 합을 최소화하자’는 방법입니다. 선형회귀의 제곱오차 비용은 가중치에 대해 볼록(convex)하여 전역 최솟값을 구할 수 있습니다. 단, 입력 정보가 중복되면 최적 가중치가 유일하지 않을 수 있습니다.

강의 p. 42의 해 공식까지 보기
w₁ = Σᵢ (xᵢ−x̄)(yᵢ−ȳ) / Σᵢ (xᵢ−x̄)²
w₀ = ȳ − w₁x̄

x̄, ȳ는 평균입니다. 모든 x가 같아서 분모가 0이면 이 식으로 기울기를 정할 수 없습니다. 보충 예: x=[1,2,3], y=[2,4,6]이면 평균은 2,4이고, w₁=4/2=2, w₀=0입니다.

로지스틱 회귀: 이름은 회귀지만 분류에 사용

출처: 2주차 PDF pp. 43~46.

  1. 먼저 점수를 만듭니다: z=w₀+w₁x₁+…+wₚxₚ.
  2. sigmoid로 0~1 사이 값으로 바꿉니다: p=1/(1+e⁻ᶻ).
  3. 이진 분류라면 p를 양성 범주의 확률로 해석하고, 예를 들어 0.5를 기준으로 범주를 선택합니다.

신경망은 이런 가중합과 비선형 변환을 여러 층에 걸쳐 연결하는 것으로 이해하면 쉽습니다. p. 45는 제곱오차와 conjugate gradient를 파라미터 추정 예로 보여주지만, 분류에서 일반적으로 많이 쓰는 손실은 뒤에 배우는 교차 엔트로피입니다.

스스로 확인

Q. ‘암이 있으면 1, 없으면 0’을 예측하면 회귀일까?

분류입니다. 0과 1은 범주의 이름표입니다.

Q. 가격 예측식의 w를 찾아가는 것은 무엇인가?

파라미터 추정, 즉 모델 학습입니다. 실제 정답과 예측 사이의 비용을 줄이는 방향으로 찾습니다.

Q. 비지도학습에는 입력 데이터도 없을까?

아닙니다. 입력 X는 있고 정답 Y가 없습니다.
