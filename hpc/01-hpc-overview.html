1. HPC 개요#

고성능 컴퓨팅 (HPC, High Performance Computing)#

HPC: 병렬로 작동하는 강력한 프로세서 클러스터를 사용하여 방대한 다차원 데이터 세트를 처리하고 복잡한 문제를 매우 빠른 속도로 해결하는 기술

  • 현재 가장 복잡한 컴퓨팅 문제를 실시간으로 해결
  • 보통 가장 빠른 상용 데스크톱·노트북·서버 시스템보다 100만 배 이상 빠른 속도로 실행

슈퍼컴퓨터#

1960년대 Cray란 인물이 만든 회사의 시스템에 슈퍼컴퓨터란 말이 최초로 쓰임.

시험 포인트

초기 vs 최근 슈퍼컴퓨터의 구조 차이

초기 최근
구성 트랜지스터를 많이 집어넣어 연산능력이 뛰어난 하나의 코어를 사용하는 CPU 기반 시스템 여러 개의 코어 기반 CPU와 GPU를 사용하는 수많은 계산 노드들이 병렬로 작동하는 프로세서 클러스터
한계 트랜지스터 증가 → 전기 소모 증가 → 발열 증가 → 연산 오류 발생 가능 —

단일 코어 성능 향상이 발열의 벽에 막혀서 병렬화로 방향이 바뀐 것이 핵심.

슈퍼컴퓨터라는 명칭을 얻으려면 Top500 목록(https://top500.org/lists/top500/)에 포함되어야 한다.

사용 분야#

  • 기상예보, 암호해독, 핵실험 시뮬레이션, 분자물리학 시뮬레이션
  • DNA 염기서열 분석
  • 주식거래 자동화
  • 인공지능(AI) 알고리즘 및 시뮬레이션 (예: 자율주행 자동차 알고리즘)
  • IoT 센서·레이더·GPS에서 실시간 테라바이트 규모 데이터 스트리밍 분석

HPC의 특징 3가지#

시험 포인트

대규모 병렬 컴퓨팅 / HPC 클러스터 / 고성능 구성요소 — 세 가지로 묶어서 외울 것

대규모 병렬 컴퓨팅
병렬 컴퓨팅은 여러 컴퓨터 서버(계산 노드) 또는 프로세서(CPU, GPU)에서 동시에 여러 작업을 실행하는 것. 대규모 병렬 컴퓨팅은 수만에서 수백만 개에 이르는 프로세서 또는 프로세서 코어를 사용하는 병렬 컴퓨팅.
HPC 클러스터
병렬 컴퓨팅 작업부하를 관리하는 중앙집중식 스케줄러(PBS, Slurm, LSF)와 함께 초고속 네트워크(InfiniBand, Omni-Path)로 연결된 여러 고속 컴퓨터 서버로 구성.
고성능 구성요소
고속 및 높은 처리량을 제공하는 네트워크, 메모리, 스토리지, 파일 시스템 사용.

HPC의 SW 구성요소#

시험 포인트

5가지 구성요소와 각각의 대표 예시를 짝지어 묻기 좋다.

구성요소 역할 예시
프로비저닝(provisioning) 도구 관리 서버에 설치하여 계산 노드들을 묶어서 클러스터를 구성하게 해주는 소프트웨어 Warewulf, xCAT
작업 스케줄러(job scheduler) 관리 서버에서 사용자의 작업들을 계산 노드들에게 적절히 할당 Slurm, PBS Pro, OpenPBS, LSF, TORQUE
각종 라이브러리 특정 용도에 맞는 라이브러리·컴파일러 제공 MKL(math kernel library), NetCDF, Intel compiler, GNU compiler, VTune profiler
모니터링 툴 관리 서버에서 계산 노드의 상태와 네트워크를 모니터링 Nagios
통합 클러스터 관리자 위의 것들을 모아서 하나의 패키지로 제공 OpenHPC

HPC 클러스터 아키텍처#

          인터넷
            │
      ┌─────────────┐
      │  마스터 노드  │ ← Provisioning, 작업 스케줄링
      └─────────────┘
            │ Ethernet (전원 제어 및 HW 상태 모니터링)
            │
      ┌─────────────┐
      │   계산 노드   │ (여러 대)
      └─────────────┘
            │ InfiniBand, Omni-Path (초고속 네트워크)
            │
      ┌─────────────┐
      │ 병렬 IO 시스템 │ ← 데이터 송수신 및 저장
      └─────────────┘
구분 용도
마스터 노드 프로비저닝, 작업 스케줄링, 모니터링
계산 노드 실제 연산 수행
Ethernet 전원 제어 및 HW 상태 모니터링
InfiniBand / Omni-Path 노드 간 초고속 네트워크
병렬 IO 시스템 데이터 송수신 및 저장

CPU와 GPU의 하드웨어 구조#

구조
Multi-core CPU 소수의 고성능 코어
NVIDIA GPU (예: Fermi 아키텍처) Streaming Multiprocessor(SM) 안에 다수의 CUDA core

참고

SM(Streaming Multiprocessor) 과 CUDA core의 관계는 CUDA 스레드 계층에서 블록·스레드와 연결된다. - CUDA core → 스레드 처리 - SM → 블록 처리 - GPU(device) → 그리드 처리
