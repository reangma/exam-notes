3. GPGPU 및 병렬처리#

GPU와 GPGPU#

GPU
그래픽스 연산(이미지 데이터를 화면에 표현하기 위해 화면을 구성하는 여러 픽셀의 색상값을 계산)에 특화된 장치
  • 같은 연산을 여러 픽셀에 적용하므로 저사양의 많은 코어 사용
  • 고대역폭 메모리(GDDR6, HBM) 사용
GPGPU (General-Purpose computing on Graphics Processing Units)
GPU를 일반적인 목적에 사용한다는 것
  • GPU의 연산 기능을 픽셀 색상 계산뿐만 아니라 다양한 연산에 적용
  • 적용 분야: 행렬 연산, 인공지능, 암호화폐

벡터화 (vectorization)#

SIMD (Single Instruction Multiple Data)
하나의 명령어로 여러 데이터를 처리하는 기술 (= 벡터화)
  • 하나의 명령어로 전용 레지스터에 있는 여러 데이터(벡터) 를 동시에 처리
  • 벡터 연산에 사용됨
  • 비교: SISD는 스칼라 연산 (하나의 명령어가 하나의 데이터를 처리)

병렬화 (parallelization)#

시험 포인트

태스크 병렬화 vs 데이터 병렬화 — 정의와 예시를 구분

구분 정의 예
태스크 병렬화(task parallelism) 여러 작업을 여러 코어에서 실행 여러 함수 실행
데이터 병렬화(data parallelism) 데이터를 나눠서 여러 코어에서 실행 행렬 연산

GPU는 둘 다 가능하지만, SIMT를 활용한 데이터 병렬처리에 더 적합하다.

SIMT (Single Instruction Multiple Thread)#

중요

SIMT vs SIMD — 가장 헷갈리는 지점

SIMT (GPU) SIMD (CPU)
풀네임 Single Instruction Multiple Thread Single Instruction Multiple Data
처리 단위 하나의 제어장치의 명령어로 연속된 32개의 스레드(워프) 가 동시에 여러 데이터에 접근하여 처리 하나의 명령어로 전용 레지스터에 있는 여러 데이터(벡터) 를 동시에 처리
레지스터 각 CUDA 스레드가 자신만의 레지스터를 가짐 전용 벡터 레지스터 공유

워프(warp): 연속된 32개의 스레드

CPU와 GPU의 코어 비교#

구성#

코어 구성
CPU의 core ALU(산술논리연산장치) + 제어장치(control unit) + L1 cache
GPU의 core ALU만으로 구성 (연산에 특화됨)

장단점#

시험 포인트

어떤 연산에 어떤 장치가 유리한가 — 표를 통째로 외울 것

CPU GPU
운영체제 실행 가능 불가능
분기문이 많은 불규칙한 흐름 높은 성능 (유리) 취약
연속되지 않은 메모리 접근 높은 성능 (유리) 취약
분기문이 적고 연속된 메모리 접근 (예: 행렬 연산) 낮은 성능 (불리) 최적

사양 비교#

구분 CPU GPU
코어 수 1 ~ 수십 개 수백 ~ 수천 개
코어 성능 2~5 GHz 1~2 GHz
메모리 크기 수십 GB ~ ~ 수십 GB
메모리 대역폭 수십 GB/s 수백 GB/s (GDDR6, HBM)

중요

GPU는 코어 하나하나는 CPU보다 느리다(1~2GHz vs 2~5GHz). 대신 개수가 압도적으로 많고 메모리 대역폭이 높다. 그래서 SIMT 기반의 데이터 병렬 연산에 적합하다.
